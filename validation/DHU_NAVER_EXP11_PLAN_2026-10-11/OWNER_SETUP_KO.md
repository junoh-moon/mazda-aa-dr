# DHU 시험 11 소유자 준비 사항

시험 11은 소유자의 손이 필요 없습니다. 폰을 옮기거나 GPS·위치 설정을 바꾸실 필요가 없습니다.

1. **폰은 지금 그대로 두십시오.** 잠금이 풀린 상태로 USB에 연결해 두시면 됩니다.
2. **헤드유닛 서버 켜짐.** 이미 켜져 있으면 그대로 두십시오(Android Auto 설정 → ⋮ → "헤드유닛 서버 시작").
3. **에이전트 시작.** README 맨 위 지시문의 `COMMIT_TO_PIN`을 실제 커밋으로 바꿔 붙여 넣으십시오. ADB 허용 창이 뜨는 경우에만 "항상 허용"
   후 허용을 누르십시오(이미 승인되어 있으면 뜨지 않습니다).
4. 시간은 Tier 0 시작부터 약 25분입니다(Tier 0 4~6분 + 회차 4개 각 약 4.5분). Tier 0 결과는 끝나는 즉시 따로 올라옵니다.

참고: 이번에는 DHU 설정 파일에 위성 센서 한 줄이 추가됩니다. 이것이 길안내 준비를 깨는지 Tier 0이 먼저 확인하고, 깨면 기존 설정으로
돌아가 위성 없이 진행합니다. 결과는 준비되는 대로 바로 올라옵니다(05:55~06:10 KST만 피함). 에이전트는 폰 설정을 바꾸지 않습니다.
