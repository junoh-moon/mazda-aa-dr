## 수정 전 재현과 통합 검사

위치 순번 소진에서는 ASan/UBSan이 `Event[128]`의 index 129 범위 위반과
충돌을 보고했습니다. 실제 차량에서 순번이 소진됐다는 주장은 아닙니다.

통합 소스의 ASan/UBSan navigation **2,414개** 검사가 통과했습니다.

최초 실행에서는 제가 stock·release 경로를 지정하지 않아 설치 검사 **21개가
생략**됐습니다. `/stock`과 이번 ARM 제품 디렉터리를 지정해 해당 21개를
별도 실행했고 모두 통과했습니다. 남은 생략은 없으며 두 로그를 모두 보존합니다.

고정 GCC 4.9.1로 57개 입력과 ARM 산출물 5개를 새로 기록했습니다.
제품 DSO 해시는 외부 수정본과 같습니다. 전체 ARM runner의 종료 코드 0과
시작·종료 입력 검증을 확인했습니다. navigation 2,414개, journal 결과 의미
12개와 제품 DSO의 위치 8·요청 14·세션 29·버스 31개 검사를 포함합니다.
worker 시험의 임시 journal은 기본 정리로 삭제되어 별도 분석기로 재감사하지
못했습니다. 해당 시험의 assertion·stdout은 보존했으며 별도 journal 감사
완료를 주장하지 않습니다.

## 원본 LDS→제품 실행 R18

[이전 R17](LDS_GPIO_2026-09-30.md)의 initrd에서 제품 DSO와 그 해시·심볼
주소를 참조하는 작성 진단 호출기를 교체했습니다. 파일·디렉터리·링크 등
**10,150개 항목**을 대조했고 변경은 이 두 파일뿐입니다. 원본 커널·LDS·설정,
NMEA·센서 공급기와 기동 절차는 보존했습니다. 직접 합성 위치 callback을
호출하지 않고 원본 LDS 파서→BLM 요청·큐→AA 로컬 송신 경로를 사용합니다.

공개 GPIO 패치로 QEMU를 다시 빌드했고 이전과 같은 바이너리 해시 및
qtest **7개 통과**를 확인했습니다. 두 핀의 부분 모델을 명시적으로 켰으며
호스트 네트워크·장치·공유 디렉터리를 VM에 연결하지 않았습니다.
helper 종료 **124**, QEMU 종료 **0**, guest 완료 표식과 진단·공급기 종료
**0**을 확인한 뒤 로그 해시를 고정했습니다. 제한 시간 자체는 PASS가 아닙니다.

- 원본 위치 **26건**: mode 1은 19건, mode 0은 7건입니다.
- LOCATION **26건**의 48바이트는 원본과 같고 하위 API 반환은 0입니다.
- raw **1,329개**, MODEL 유효 SHADOW snapshot **56개**를 보존했습니다.
- wheel 최대 수신 간격은 **93.271ms**, 150ms 초과는 0회입니다.
- GPS 복귀 뒤 유효 MODEL 철회, drop·audit·요청/세션/bus fault 0을 확인했습니다.
- 일반 분석은 **inconclusive 21**, violation 0이며 모든 `assist_ready`는 false입니다.

**검증기 정정:** 최초 독립 계산은 가장 최근 mode-1 응답을 기준점으로 가정하여
실패했습니다. R18의 9번 응답은 앞선 기준점보다 약 963ms 늦어 제품의 1초
GPS 쌍 조건에서 `WAITING`이었습니다. 별도 calibration 로그는 8번 응답의
`ACCEPTED`와 9번의 `WAITING`을 기록했습니다. 예측 좌표를 보기 전에 이
수락 기록으로 기준점을 고르고, 이후 응답이 1초 미만의 WAITING인지 검사하도록
검증기를 정정했습니다. 가장 잘 맞는 좌표를 골라 기준점으로 삼지 않았습니다.

수락한 기준점에서 10m/s 직진 거리를 WGS84 자오선 수치 적분·역산과 대조한
56개 결과의 최대 수치 차이는 `3.17e-9 m` 미만입니다. 이전 R17에도 정정한
검증기를 적용해 기존 9번 기준점과 51개 결과가 유지됨을 확인했습니다.
이는 합성 입력의 계산 일치이며 물리 위치 정확도 수치가 아닙니다. 제품 코드나
신선도 조건을 바꾸지 않았고 최초 실패의 코드·로그도 보존했습니다.

AA 서비스에는 미시작 세션의 요청 거절이 있습니다. 반환 0은 폰 수용이 아닙니다.
실제 보정 위치의 ASSIST 선택, 센서 생산 시각·물리 품질과 출처, 요청의
provider/receiver/session 자격, 폰/앱 수용과 정상 차량 기동·복구는 남아 있습니다.
차량·폰 시험은 요청하지 않았으며 공개 ZIP이나 v1.0 완료 표시는 바꾸지 않았습니다.
