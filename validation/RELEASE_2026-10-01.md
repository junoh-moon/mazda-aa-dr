# v0.3.2-shadow.1 설치 ZIP 검증

이 문서는 외부 master `90a0173`의 발행·검증 기록입니다. 아래 빌드·host/ARM·
원본 BusyBox와 Claude 호출은 해당 작성자의 실행이며 이번 작업의 검사로
합산하지 않습니다. 이번 작업의 공개 ZIP 다운로드 대조와 추가 후보는
[시험 준비 기록](TRIAL_PREPARATION_2026-10-01.md)에 구분합니다.

대상은 1세대 Mazda Connect NA 74.00.324A입니다. 이 릴리즈는 SHADOW
시험 후보입니다. MODEL 위치를 기록하지만 순정 위치 송신을 유지하고 live
ASSIST는 차단합니다. 차량 기동·물리 센서·위치 정확도·폰/앱 수용을 확인한
v1.0 완성판이 아닙니다.

## 이번 커밋·최종 ZIP의 실행 검사

1. Debian 12 x86 컨테이너에서 최종 ZIP에서 꺼낸 묶음과 원본 펌웨어 fixture를
   명시하고 `make test` 전체 통과, 종료 코드 0, 실제 skip 0. Python 346개
   (빌드 41, motion 94, recovery 28, loader 1, collector 10, packaging 142,
   tools 30)와 C/C++ 실행을 포함합니다.
2. 고정 ARM 도구체인과 해당 다섯 바이너리로 전체 QEMU 합성 검사 통과,
   종료 코드 0. 첫·끝 `ARM_TEST_INPUTS`의 `release_verified=true`, compiler,
   sysroot와 다섯 해시가 일치했습니다. navigation 2,740, gyro 2,677,
   GPS/wheel 84,601, holdout 5,443개 합성 검사와 실제 ARM DSO
   position/request/session/bus 후크 검사를 포함합니다.
3. ZIP 35개 파일의 CRC와 전체 `SHA256SUMS` 통과. 최상위에 `install.sh`,
   `mp3/`, `js/`가 있으며 정적 ARM 해시 도구가 포함됩니다.
4. 원본 ARM BusyBox 1.19.2/libc를 쓰는 격리 chroot에서 최종 ZIP을 풀어
   손상 USB 거부, SHADOW 기본 설치, loader, 일회 기동, collector UID/종료,
   주차 중 상태·종료·회수, 기존 touch 설정 변경 뒤 재예약, 제거·재설치를
   실행했습니다. 마운트와 센서 상태 행은 합성 fixture입니다. 실제 OEM
   서비스·차량 구동을 이 검사에서 실행한 것은 아닙니다.

이번 릴리즈용 새 Claude Code 정적 리뷰 호출은 `Execution error`로 끝나
검토 결과를 얻지 못했습니다. 이전 코드 단위의 리뷰·원본 VM 실행은 각각의
기록에만 해당하며, 이 최종 ZIP의 별도 OEM 전체 기동이나 차량 검증으로
합산하지 않았습니다.

## 남은 증거

원본 LDS의 위치 응답과 별도 진단에는 같은 생산 측정 ID가 없습니다.
[출처 검토](LDS_DIAGNOSTIC_PROVENANCE_REVIEW_2026-10-01.md)대로 사후
polling을 요청별 receiver·sensor 자격으로 승격할 수 없습니다. 생산자 측정
시각·품질과 실제 요청/응답·세션 자격의 연결, 물리 센서 단위와 보정,
정상 전체 차량 기동·복구, Galaxy S25/무선 AA/네이버 지도의 자체 위치 수용이
남습니다. 원본 펌웨어·OEM 바이너리·전체 로그·개인 공유 링크는 공개하지
않습니다.
