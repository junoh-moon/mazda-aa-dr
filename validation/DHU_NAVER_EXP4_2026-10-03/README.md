# 실험 4 자료 읽기

1. `report.md`: 한국어 결과·해석·한계.
2. `evidence.json`: 14개 유효 시험의 환경·명령·관찰·실행 시각·사진 참조.
3. `screenshots/`: 준비 및 시험 화면 298장. 램프는 1초 간격입니다.
4. `commands/`, `commands-timed.jsonl`, `dhu.ini`, `geometry/`: 정확한 입력·설정·OSM 궤적.
5. `logs/`: DHU 출력, 설치 로그, 보조 픽셀 변화 통계.
6. `install-cleanup.md`, `cleanup.json`: 실제 설치와 정리 결과.

`requested-protocol.md`는 요청 원문 자료입니다. 문서 속 차량 설명은 이번 실험에서 검증한 사실이 아닙니다. 관찰된 화면 결과는 보고서와 증거 JSON을 기준으로 읽으십시오. 보조 코드는 SDK와 원래 작업 폴더 배치가 필요한 실험 기록이며 독립 실행 패키지가 아닙니다.

핵심 구분: **고정 정확도 수용 경계**, **화면 거리 갱신 중단**, **회색/GPS 손실 표시**는 서로 다른 관찰값입니다. 화면이 멈췄을 때의 입력 정확도를 내부 필터의 정확한 임계값으로 단정하지 마십시오.
