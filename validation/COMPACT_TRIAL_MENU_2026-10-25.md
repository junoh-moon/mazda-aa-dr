평소 쓰는 것은 설치·재부팅·종료·데이터 추출·제거·로그까지 완전 삭제라고 설명했다.
처음에는 후속 소스로 분리했으나, 소유자가 이어서 **“beta 1에 반영해줘”**라고
명시 지시했다. 아직 태그·릴리즈가 없음을 확인했으므로, v1.1.0-beta.1을 새 커밋에
고정하고 설치 ZIP과 발행 검증을 새 WORK에서 다시 만든다. 이전 미발행 후보
`2e9a920b4c84392d122e016d192458d1bf45ae31`의 ZIP·시험 기록은 보존하되
새 후보의 실행 결과로 재사용하지 않는다. 차량·폰·DHU에서는 실행하지 않았다.

## 바뀐 화면

첫 화면은 아래 항목만 한 줄씩 표시한다. `2`는 주차 중 재부팅·수집 상태 확인을
위해 유지한다. 번호 0–6은 기존 의미 그대로다.

| 번호 | 작업 |
|---|---|
| 1 | 설치 / 다시 활성화 |
| 2 | 상태 확인 |
| 3 | 데이터·로그 추출(그 부팅 수집 종료) |
| 4 | 제거(로그 보존) |
| 5 | CMU 재부팅 |
| 6 | 로그까지 완전 삭제(4 → 5 이후, 6 재확인 필요) |
| 99 | 고급 설정 |
| 0 | 메뉴 종료 |

- 고급 화면에만 기존 7(VIM 기록), 8(G3), 10(정확도 상한), 11(BT),
  12(지하 이월), 13(터널 지도, BETA만)을 나열한다. `0`은 첫 화면으로 돌아간다.
- 기존 번호를 첫 화면에서 직접 입력하는 경로도 유지한다. 과거 숫자 절차와
  시험이 잘못된 작업을 가리키지 않게 번호를 재배정하지 않았다. 메뉴 9는 계속 없다.
- 화면 이동만으로 표식·설정·설치 상태는 바뀌지 않는다. 토글의 같은 번호 재확인과
  메뉴 6의 두 번째 `6`, EOF·다른 입력의 취소는 그대로다.
- 항목 사이 빈 줄과 긴 설명을 없앴다. 첫 화면에 모드, 설치 1 → 5 → 2,
  USB 연결 유지, 주차·실제 엔진 가동·ACC 금지는 짧게 남겼다.
- 메뉴 2 뒤에는 전체 목록을 다시 뿌리지 않아 GO/NO-GO 판정이 밀려나지 않는다.
  고급 화면에서 상태 확인을 직접 실행해도 짧은 `0 Back` 프롬프트만 덧붙인다.
- **G3·TAN 등 기능 기본값과 제품 송신·설치/제거 동작은 바꾸지 않았다.**
