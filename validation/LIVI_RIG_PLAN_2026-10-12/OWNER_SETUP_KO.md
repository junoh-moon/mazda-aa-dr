# LIVI rig 소유자 준비 사항

손 쓸 일은 DHU 시험과 거의 같습니다. 빌드와 실행, 사진, 업로드는 노트북의 에이전트가 합니다. 회기 하나는 Tier 0 시작부터
약 25분입니다(준비 빌드는 회기 전에 에이전트가 따로 하며 약 15~25분, 손이 필요 없습니다).

1. **폰(S25)을 Mac에 USB로 연결하고 잠금을 풀어 두십시오.** DHU 때처럼 그대로 두시면 됩니다. "헤드유닛 서버"는 이번에는
   필요 없습니다(켜져 있어도 됩니다).
2. **에이전트 시작.** README 11절 지시문의 `COMMIT_TO_PIN`(그리고 리드가 알려 주면 `RIG_ZIP_URL`/`RIG_ZIP_SHA256`)을
   바꿔 붙여 넣으십시오. 회기 번호(1, 2, 3)도 적어 주십시오. 회기 1은 Tier 0 + 회차 3~4개, 회기 2는 짧은 Tier 0 + 회차 3~4개,
   회기 3은 선택(반복)입니다.
3. **창이 뜰 때만 누르십시오.** 처음 한 번만 뜰 수 있는 것들입니다(이미 허용되어 있으면 뜨지 않습니다):
   - 폰: Android Auto의 새 차량 연결 동의 창, ADB 허용 창("항상 허용" 후 허용).
   - Mac: 터미널의 "화면 기록" 권한 창(사진 촬영용), LIVI의 USB·로컬 네트워크 관련 확인 창.
   - Mac에 Xcode Command Line Tools가 없으면 설치 창이 뜰 수 있습니다(빌드에 필요).
4. **관리자 암호는 원래 필요 없습니다.** 에이전트가 경로 A(이미 만들어진 LIVI 앱에 수정한 실행 파일 하나만 바꿔 넣음)에
   실패해 경로 B(GStreamer 설치)가 필요하다고 알릴 때만 Mac 암호를 입력해 주십시오. 경로 A에 쓰는 upstream 앱 파일은
   2026-10-18 저녁(한국 시각 10-19 새벽)에 GitHub에서 만료되므로 그 전에 첫 빌드를 해 두면 좋습니다.

에이전트는 폰 설정을 바꾸지 않고, LIVI 설정 파일은 회기 끝에 원래대로 되돌립니다. 결과(사진 전부 포함)는 준비되는 대로
바로 올라옵니다(매일 05:55~06:10 KST만 피함). 원하시면 시험이 모두 끝난 뒤 폰의 Android Auto 설정에서 "LIVI" 차량을 지우셔도
됩니다(필수 아님).
