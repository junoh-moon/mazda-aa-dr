# DHU 시험 5 결과 — 2026-10-05

[계획](../DHU_NAVER_EXP5_PLAN_2026-10-05/README.md)대로 사용자 노트북에서 코딩 에이전트가 수행했다(Galaxy S25, 네이버 지도 6.10.0.16, Android Auto 17.7, DHU 2.0, USB ADB). `report.md`가 원 보고서, `evidence.json`이 정형 결과다.
회차당 1회, 10초 간격 화면 표본이며 Mazda 형식·무선 동글·차량 속도는 시험하지 않았다. 스크린샷 두 장(E1 310초, E2 330초)은 레포 쪽에서 직접 열어 아래 분류를 확인했다.

## 결과(BETA 판단에 쓰는 것)

- **E1(저장 좌표·정확도 8.8 m·방위 335° 고정, 속도만 0↔14 m/s)**: 600초 동안 61장 모두 파란 화살표, 회색·위성-X 없음, 남은 거리 2.4 km 유지, 표시 속도는 정속 구간 50, 가속 직후 45, 정지 구간 0 km/h로 **입력 속도를 따랐다.** 화살표 방향의 이상 거동은 보이지 않았다. → BETA의 NO_FIX 속도 덮어쓰기 형태는 이 조건에서 **통과**.
- **E5(순정 모사: 속도 1.111 m/s 상수)**: 13장 모두 파랑이지만 **표시 속도가 전부 0 km/h**. 순정 형태는 속도 표시가 죽어 있고, E1은 속도가 살아난다(속도 쪽 개선).
- **E2(E1에서 방위만 `NAN`)**: 61장 중 50장이 회색, 위성-X 반복. **방위 필드를 지우는 안은 나쁘다.** → 덮어쓰기에서 방위(`hasBearing`)를 지우지 않는다.
- **E3(저장 구간 60초 → 44 m 앞 첫 fix(정확도 3 m, 속도 0, 방위 없음) 20초 → 정상 이동)**: 35장 모두 파랑. 정상 이동 단계는 따라갔다(2.4→1.5 km). **첫 정지 fix의 44 m 이동은 화면에 반영되지 않았다**(남은 거리·안내 거리 불변; 순정 동작과 같은 형태이며 BETA가 새로 만든 문제가 아니다. 이동이 시작되면 따라온다).
- **E6(정확도 `NAN` 순정 mode 0 형식, 2.2 m/s)**: 23장 모두 파랑, 표시 속도 0, 위치 고정, 복귀 후 점프 없음. 이 형식이 화면상 "GPS 끊김"이라는 가정은 확인되지 않았다(2차 시험의 "정확도 없음+속도≠0=끊김"과 다르다).
