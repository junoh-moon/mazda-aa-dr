# DHU 시험 10 v5 소유자 준비 사항

v5는 소유자의 손이 필요 없습니다. 폰을 옮기거나 GPS·위치 설정을 바꾸실 필요가 없습니다(정확도 1 m 주입으로 폰 자체 위치와의
경쟁을 넘으려는 계획입니다).

1. **폰은 지금 그대로 두십시오.** 잠금이 풀린 상태로 USB에 연결해 두시면 됩니다.
2. **헤드유닛 서버 켜짐.** 이미 켜져 있으면 그대로 두십시오(Android Auto 설정 → ⋮ → "헤드유닛 서버 시작").
3. **에이전트 시작.** README 맨 위 지시문의 `COMMIT_TO_PIN`을 실제 커밋으로 바꿔 붙여 넣으십시오. ADB 허용 창이 뜨는 경우에만 "항상 허용"
   후 허용을 누르십시오(v1 정리 때 지워진 키를 다시 승인하는 창입니다. 이미 승인되어 있으면 뜨지 않습니다).
4. 시간은 Tier 0 시작부터 약 25분입니다(Tier 0 5~7분 + B2·B3·B1 각 4~5분). Tier 0 결과는 끝나는 즉시 따로 올라옵니다.

결과는 준비되는 대로 바로 올라옵니다(05:55~06:10 KST만 피함). 에이전트는 폰 설정을 바꾸지 않습니다.
