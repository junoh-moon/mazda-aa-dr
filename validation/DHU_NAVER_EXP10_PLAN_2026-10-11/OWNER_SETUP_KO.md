# DHU 시험 10 v3 소유자 준비 사항

v1 실행 에이전트가 정리 단계에서 **USB 디버깅을 끄고 노트북의 ADB 키를 지웠습니다.** 그래서 오늘 밤은 아래 1~2번에 소유자의 손이 꼭
필요합니다.

1. **(필수) USB 디버깅 다시 켜기.** 폰 설정 → 개발자 옵션 → USB 디버깅 켜기. 노트북과 Galaxy S25를 USB로 연결합니다.
2. **(필수) 잠들기 전에 에이전트를 시작하고 ADB 승인 누르기.** README 맨 위 지시문의 `COMMIT_TO_PIN`을 실제 커밋으로 바꿔 노트북 에이전트에게
   붙여 넣으십시오. 에이전트가 처음 `adb devices`를 실행하면 폰에 "USB 디버깅을 허용하시겠습니까?" 창이 뜹니다. "이 컴퓨터에서 항상 허용"을
   켜고 허용을 누르십시오. 이 창은 소유자만 누를 수 있습니다.
3. **(필수 확인) 헤드유닛 서버 켜짐.** Android Auto 설정 → ⋮ → "헤드유닛 서버 시작"이 켜져 있는지 확인하십시오.
4. 시험 6~9 때와 같은 상태로 두십시오: 네이버 지도 최근 목적지의 첫 줄이 **모라역**(부산2호선)인지 확인하고, 아니면 한 번 검색해 안내를
   시작했다가 끄십시오. 네이버는 강제 종료하지 마십시오(v3 기본 회차는 네이버가 켜진 채 DHU만 다시 시작합니다). 폰은 충전 중으로 둡니다.
5. (선택, 권장) Tier 0 결과(PASS/ABORT)는 시작 약 20분 뒤 transfer에 따로 올라옵니다. 기다리시면 ABORT일 때 바로 판단하실 수 있습니다.
6. (선택) 방해 금지 모드. v1에서 Gemini 겹친 창이 한 번 보였습니다. (선택) Play 스토어 자동 업데이트를 오늘 밤만 끄기.

결과는 준비되는 대로 바로 올라옵니다(Tier 0 직후 한 번, 끝난 뒤 텍스트 ZIP·사진 ZIP·요약). 05:55~06:10 KST에만 업로드를 피합니다.
사진 ZIP에는 모든 시도의 모든 screenshot이 원본 그대로 들어 있습니다. 끝난 뒤 USB 디버깅을 다시 끌지는 소유자가 정하십시오(v3 에이전트는
폰 설정을 바꾸지 않습니다).
