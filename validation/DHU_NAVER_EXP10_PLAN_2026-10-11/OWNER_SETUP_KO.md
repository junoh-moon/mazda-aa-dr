# DHU 시험 10 v4 소유자 준비 사항

v3는 위치(5 m)는 통했지만 안내 시작 탭이 맞지 않아 Tier 0에서 멈췄습니다. v4는 시험 6~9가 실제로 한 준비(검색 → 최근 목적지의 모라역 →
경로 시작)를 씁니다. 소유자의 손은 아래 단계에만 필요합니다. 각 단계는 한 번이면 됩니다.

## 지금(아침) 2분 확인(권장, v4 판단을 확실하게 함)

DHU가 켜져 있고 네이버 빈 지도가 보이는 상태에서 하십시오. 꺼져 있으면 에이전트에게 "DHU만 켜 달라"고 하십시오.

1. **45초 동안 아무것도 누르지 마십시오.** 오른쪽 위 둥근 버튼 4개(집·돋보기·핀·톱니)가 사라지는지 보십시오.
2. **DHU 창의 돋보기 자리를 마우스로 한 번 누르십시오.** 버튼만 다시 나타나는지, 검색 화면이 열리는지 보십시오.
3. **2초 안에 돋보기를 한 번 더 누르십시오.** 이번에 검색 화면이 열리면 "숨은 버튼" 원인이 맞습니다. 검색 화면은 X로 닫으십시오.
4. **에이전트에게 부탁하십시오:** "45초 기다린 뒤 시험 9 제어기로 tap 600 44를 2초 간격으로 두 번 보내고 각각 사진을 찍어 주세요."
5. **비교.** 4가 2·3과 같게 움직이면 콘솔 탭은 정상입니다. 4에서 화면이 전혀 안 바뀌면 콘솔 전달 문제입니다. 본 것을 한 줄로 보내 주십시오.

## 실행 전 준비(필수)

1. **USB 디버깅 켜짐 확인.** 폰 설정 → 개발자 옵션 → USB 디버깅. 노트북과 Galaxy S25를 USB로 연결하고 폰 잠금을 푸십시오.
2. **헤드유닛 서버 켜짐 확인.** Android Auto 설정 → ⋮ → "헤드유닛 서버 시작".
3. **모라역을 최근 목적지 첫 줄로.** 폰의 네이버 지도에서 "모라역"(부산2호선)을 검색해 길안내를 시작한 뒤 바로 안내 종료를 누르십시오.
4. **확인.** 네이버 검색 화면의 최근 목적지 맨 위가 "모라역 부산2호선"인지 보십시오. 다른 곳이면 3을 다시 하십시오.
5. **네이버는 켜 둔 채로.** 강제 종료하지 마십시오. 안내는 꺼진 상태로 두십시오(에이전트가 회차마다 직접 시작합니다).
6. **에이전트 시작.** README 맨 위 지시문의 `COMMIT_TO_PIN`을 실제 커밋으로 바꿔 붙여 넣으십시오. ADB 허용 창이 뜨면 "항상 허용" 후 허용.
7. **(선택) 방해 금지 모드, Play 스토어 자동 업데이트 끄기.** 실행 중 전화·알림 창은 회차를 무효로 만듭니다.

결과는 준비되는 대로 바로 올라옵니다(Tier 0 직후 한 번, 끝난 뒤 텍스트 ZIP·사진 ZIP·요약). 05:55~06:10 KST에만 업로드를 피합니다.
에이전트는 폰 설정을 바꾸지 않습니다. 끝난 뒤 USB 디버깅을 끌지는 소유자가 정하십시오.
