# DHU 시험 10 v2 소유자 준비 사항

v1 실행 에이전트가 정리 단계에서 **USB 디버깅을 끄고 노트북의 ADB 키를 지웠습니다.** 그래서 오늘 밤은 아래 1~2번에 소유자의 손이 꼭
필요합니다. 나머지는 선택입니다.

1. **(필수) USB 디버깅 다시 켜기.** 폰 설정 → 개발자 옵션 → USB 디버깅 켜기. 노트북과 Galaxy S25를 USB로 연결합니다.
2. **(필수) 에이전트를 잠들기 전에 시작하고 ADB 승인 받기.** README 맨 위 지시문의 `COMMIT_TO_PIN`을 실제 커밋으로 바꿔 노트북 에이전트에게
   붙여 넣으십시오. 에이전트가 처음 `adb devices`를 실행하면 폰에 "USB 디버깅을 허용하시겠습니까?" 창이 뜹니다. "이 컴퓨터에서 항상 허용"을
   켜고 허용을 누르십시오. 이 창은 소유자만 누를 수 있습니다.
3. **(필수 확인) 헤드유닛 서버 켜짐.** v1 에이전트는 폰이 잠겨 있어 서버를 끄지 못했다고 적었습니다. Android Auto 설정 → ⋮ → "헤드유닛 서버
   시작"이 켜져 있는지 확인하십시오(꺼져 있으면 켜 주십시오).
4. 폰은 충전 중으로 두십시오. 네이버 지도는 안내 중이 아니어도 되고 닫혀 있어도 됩니다(에이전트가 매 회차 강제 종료하고 다시 엽니다).
   최근 목적지에 모라역이 남아 있으면 좋지만 없어도 에이전트가 화면 키보드로 찾습니다.
5. (선택, 권장) 에이전트가 Tier 0 결과(PASS 또는 ABORT)를 알릴 때까지 약 20분 기다리시면, ABORT일 때 오늘 밤을 쓸지 바로 정할 수 있습니다.
   기다리지 않으셔도 ABORT이면 에이전트가 진단 묶음만 올리고 끝냅니다.
6. (선택) 방해 금지 모드. v1에서 Gemini 겹친 창이 한 번 보였습니다. 끄는 방법을 아시면 꺼 두셔도 됩니다(에이전트는 폰 설정을 바꾸지 않음).
7. (선택) Play 스토어 자동 업데이트를 오늘 밤만 끄기. v1 밤에는 버전 변경이 없었습니다.

아침에 transfer 링크와 요약 한 문단을 확인하십시오. 끝난 뒤 USB 디버깅을 다시 끌지는 소유자가 정하십시오(v2 에이전트는 폰 설정을
바꾸지 않도록 했습니다). 폰을 직접 돌리는 Tier M은 원하실 때 따로 하시면 됩니다.
