## 실제 제품 연결과 남은 범위

[같은 제품의 LDS→AA worker 연결](LDS_PRODUCT_RUNTIME_2026-10-02.md)에서는 작성 NMEA 7회 쓰기와 원본 질의
9회가 실제 POSITION 9행·sideband 9행으로 기록되어 정확히 연결됐습니다.
원본 위치 아홉 필드·부분 할당 출처와 수신 손실 0을 대조하고 실제
`capture.done`을 확인했습니다. LDS 자동 loader와 실제 원본 parser·
callback·cache·service/client를 실행했지만 AA 시작 순서와 즉시
WorkerScope는 작성한 fixture입니다. AA sink·worker·journal은 실제
제품이며 소스 링크 formatter로 기록을 대신하지 않았습니다.

전체 분석기는 AA 정상 bootstrap을 실행하지 않은 `not_attempted`와
AA SEND 부재로 종료 2·`inconclusive`를 유지했습니다. 9개 연결 성공을
차량 세션 성공으로 바꾸지 않았으며 qualification도 `not_established`입니다.
첫 실행의 기본 수신 채널 `EADDRINUSE`를 보존했습니다. 동시 전체 검사와
충돌했을 가능성이 있으나 소유 PID를 확정하지 못했습니다. 두 전체 검사
종료 후 같은 제품·기본 채널로 단독 실행하여 위 결과를 얻었습니다.

정상 ServiceInit·SM 전체 기동, 실제 센서 단위·부호·생산 시각·품질, 실제 차량 복구와
Galaxy S25·무선 AA 동글·네이버 지도 수용은 미검증입니다. 관측 할당
출처가 물리 측정 시각이나 live ASSIST 자격을 채우지는 않습니다.
[v1.0 완료 조건](../docs/V1_READINESS_KO.md)을 유지합니다.
