# DHU 시험 12 소유자 준비 사항

시험 12(정확도 경계 시험)는 소유자의 손이 필요 없습니다. 준비는 시험 11 v4와 같고, 폰 설정이나 노트북 DHU 설정을 바꾸실 필요가 없습니다
(DHU 설정은 시험 11 첫 회기의 기본 설정 그대로이며 에이전트가 확인만 합니다).

1. **폰은 지금 그대로 두십시오.** 잠금이 풀린 상태로 USB에 연결해 두시면 됩니다. 폰을 옮기거나 GPS·위치 설정을 바꾸지 마십시오.
2. **헤드유닛 서버 켜짐.** 이미 켜져 있으면 그대로 두십시오(Android Auto 설정 → ⋮ → "헤드유닛 서버 시작").
3. **에이전트 시작.** README 맨 위 지시문의 `COMMIT_TO_PIN`을 실제 커밋으로 바꿔 붙여 넣으십시오. ADB 허용 창이 뜨는 경우에만 "항상 허용"
   후 허용을 누르십시오(이미 승인되어 있으면 뜨지 않습니다).

시간은 Tier 0 시작부터 약 25분입니다(환경 2분 + Tier 0 5~7분 + 회차 약 5분씩). 회차 순서는 V4A29 → V4A31 → V4REF → V4A25이며 뒤의 둘은
시간이 남을 때만 돕니다. Tier 0 결과는 끝나는 즉시 따로 올라오고, 나머지는 끝나는 대로 올라옵니다(05:55~06:10 KST만 피함).
