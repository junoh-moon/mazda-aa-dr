## 첫 준비 실패와 독립 확인

첫 실행은 검증 컨테이너에 `jq`가 없어 도구 목록 확인 단계에서 실패했습니다.
이때 ARM 컴파일이나 제품·원본 loader 실행은 시작되지 않았습니다. 최초
실패를 보존하고 실제 Debian `jq`와 두 의존성의 세 패키지를 해시 확인한 뒤
컨테이너 전용 경로에만 풀었습니다. 호스트·컨테이너 패키지 DB를 바꾸지
않았습니다. 실제 필드 추출 종료 0과 잘못된 JSON 종료 4를 확인했으며
검사 runner 소스는 수정하지 않았습니다. 추가 파일은 작업 종료 시 정리 대상입니다.

후속 실제 실행은 모두 첫 시도에서 통과했습니다. 별도 독립 확인은 시험
입력 80개, 실행 파일, 각 사례의 종료·로그, 원본 runtime 여덟 파일을 실제로
재해시했습니다. 원본 로더의 18개와 source-linked 18개의 개별 목록·PASS가
일치하며 메뉴의 선언·실행 수도 29개로 일치합니다. 제품·원본·소스·도구·
