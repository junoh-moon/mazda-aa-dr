## 절차

v1.0.3과 같은 수동 절차를 썼습니다. 고정 커밋이 origin/master의 조상이 아니므로 `tools/release/setup.sh`(G0)는 쓸 수 없습니다.

1. 작업 트리가 깨끗한 상태(`git status --porcelain` 비어 있음)에서 확인했습니다. `python3 tools/build_arm.py --toolchain <고정 m3-toolchain 61ec034> --build-dir <새 디렉터리>` → `Verified ARM build`. 이 단계에서 G1을 사용했습니다.
2. 여섯 산출물을 v1.0.3 ZIP의 같은 파일과 `cmp`로 비교했고, 6/6 동일했습니다.
3. `python3 tools/make_usb_zip.py --build-dir … --default-mode BETA --output mazda-aa-dr-v1.0.4.zip`(`--shell-only` 없음)를 실행했습니다. build-info는 `source_commit=734bf9f…`, `source_modified=false`, `version=1.0.4`입니다.
4. G5/G6: `g5g6_zipcheck.py --commit 734bf9f… --mode BETA --version 1.0.4 --readelf <고정 readelf>` → **67/67**.
5. 압축을 푼 묶음에서 `sha256sum -c SHA256SUMS`를 통과했습니다. `.up` 진입 파일은 1개이고 SHA256SUMS에는 들어 있지 않습니다.
6. 패키징 스위트(`MX5DR_RELEASE_BUNDLE`=압축을 푼 실제 ZIP): 469 tests OK, skip 46. skip은 순정 identity fixture 없음 39, 고정 ARM 컴파일러 경로 없음(bds 파싱) 6, host collector 빌드 없음 1입니다. `make test-packaging`은 이 호스트에 D-Bus 개발 헤더가 없어 실행하지 않고, `python3 -m unittest discover -s tests/packaging`을 직접 실행했습니다.
7. 실제 ZIP 내용으로 설치기 end-to-end를 돌렸습니다(합성 순정 트리, host guard).
   - 이 시험에서는 `firmware.sha256`만 합성 트리용으로 바꾸고, SHA256SUMS에서 그 한 줄만 고쳤습니다. 실제 파일은 OEM 해시를 고정하므로 합성 트리로는 재현할 수 없습니다.
   - 차량 내보내기 `cmu-20261025`의 실제 `sm.conf`/`sm_WCP.conf`로 BETA 설치와 enable → mazda-cmu-tune 1단계 결과로 교체 → `--check` `mismatch:baseline_edited:sm.conf` → 다음 부팅 순정 → `rebaseline.sh` `result=done` → `--check` `match` → 다음 부팅 trial 선택.
   - trial은 1단계 파일과 preload 4줄만 다릅니다.
   - 설치 뒤 `installed.txt`에 `version=1.0.4`가 있고, 설치된 `tools/rebaseline.sh`는 ZIP의 파일과 바이트 동일합니다.
8. 태그를 만들고 push한 뒤 `gh release create v1.0.4 --verify-tag --latest`로 발행했습니다.
9. G18 재다운로드: 사이드카 `sha256sum -c` OK, 빌드한 ZIP·APK와 `cmp` 동일, `unzip -t` 오류 없음, 내부 SHA256SUMS OK, build-info `source_commit`·`version` 일치, `isDraft=false`, `isPrerelease=false`, `releases/latest`=`v1.0.4`.

## 실행하지 않은 게이트 (통과로 세지 않음)

- G0 `setup.sh`: 커밋이 master 조상이 아니라 쓸 수 없었습니다. 위 1~3을 고정 커밋의 깨끗한 작업 트리에서 수동으로 실행했습니다.
- G2 `make -k test` 전체(호스트 D-Bus 헤더 없음), G3/G4 ARM 스위트와 AA 설치 프로브, G7–G9·G16 순정 BusyBox 하네스, G10 soak, G11 재생. 모두 비공개 입력(순정 루트, libpatch, 차량 부팅 목록)이 필요하며, 이 호스트에는 그 입력이 없습니다.
- G13–G15 사람 판단 게이트와 독립 검토 2라운드.
- 실차. `rebaseline.sh`는 차량에서 실행된 적이 없고, QEMU에서 실제 ARM guard로도 실행하지 않았습니다.

제품 바이너리가 v1.0.3과 바이트 동일하므로, 바이너리에 대한 이전 게이트 결과는 그대로 유지됩니다. 새로 추가된 것은 셸 스크립트 하나와 버전 표시뿐이며, 이 부분의 근거는 위 호스트 시험뿐입니다.
