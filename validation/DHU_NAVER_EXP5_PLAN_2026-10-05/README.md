# DHU 시험 5 계획: BETA의 "저장 위치 구간 속도 덮어쓰기" 확인 — 2026-10-05

**목적.** `shadow.5` 주행에서 순정은 부팅 후 12~15분 동안 **저장된 위치를 정확도 8.8 m인 정상 fix처럼** 보냈다(좌표 고정, 방위 335°, 4 km/h). BETA는 이 구간에서 **속도(바이트 32, 36~39)만 휠 속도로 바꾸고** 좌표·정확도·방위는 원본을 유지한다.
이 시험은 그 송신 형태를 네이버가 어떻게 받아들이는지 본다. 이 결과가 BETA를 차에 가져가기 전의 출하 조건이다. 차나 Mazda 형식, 무선 동글은 시험하지 않는다(DHU 한계는 [시험 4](../DHU_NAVER_EXP4_2026-10-03.md)와 같다).

**환경.** 시험 4와 같은 노트북·폰·DHU 설정(`../DHU_NAVER_EXP4_2026-10-03/dhu.ini`), 길안내 ON, 해운대해변로→미포항 경로. 명령 파일은 `python3 gen_commands.py`로 `commands/`에 생성한다
(문법은 시험 4와 같은 `location <위도> <경도> <정확도> <고도|NAN> <속도 m/s> <방위|NAN>`; 준비 단계는 시험 4의 `A40-r1-setup.txt`와 같고 스크린샷 접두만 `experiment5/`). 매 회차 전에 DHU와 안내를 다시 시작하고, 정확도 5 m·속도 0의 출발 좌표 뒤에 파란 화살표와 안내를 확인한다.

## 회차

| 회차 | 길이 | 입력 | 보는 것 |
| --- | --- | --- | --- |
| **E5 대조(순정)** | 120초 | 저장 좌표 고정, 정확도 8.8 m, 속도 1.111 m/s(4 km/h) 상수, 방위 335° | 순정 때 네이버의 모습(기준선) |
| **E1 속도 덮어쓰기(방위 335°)** | 600초 | 좌표·정확도 8.8 m·방위 335° 고정, **속도만** 0→14→0 m/s를 60초 주기로 반복 | 끊김 표시 없이 파란 화살표와 **표시 속도가 입력을 따르는지**, 10분간 유지되는지, 화살표가 335°대로 돌아가거나 이상하게 움직이는지, 남은 거리가 변하는지 |
| **E2 속도 덮어쓰기(방위 없음)** | 600초 | E1과 같고 방위만 `NAN` | 방위 필드가 없을 때 화살표·속도 표시가 어떻게 달라지는지(`NAN` 방위를 DHU가 받는지도 확인) |
| **E3 저장 구간 → 첫 fix** | 140초 | 60초 E1 형태 → 44 m 앞 첫 fix(정확도 3 m, 속도 0, 방위 없음) 20초 → 정상 이동 fix(5 m, 14 m/s) 60초 | 전환 때 위치가 튀는지, 지도가 따라오는지, 끊김이 뜨는지 |
| **E6 끊김 형식(참고)** | 110초 | 정확도 10→38 m로 커지는 이동 fix 20초 → 순정 mode 0 형식(마지막 좌표, 정확도 `NAN`, 속도 2.2 m/s) 60초 → 정상 fix 복귀 | 우리 LOST 철회 뒤의 모습(순정 mode 0과 같음)과 복귀 때 점프 |

스크린샷은 10초 간격(전환 구간은 더 촘촘). 각 회차에서 표시 속도, 화살표 방향, 남은 거리, 회색·위성-X 표시, 시각을 기록한다. 순서는 고정 시드로 무작위화하고 조합당 2회 이상 권장한다(E1은 시간이 길어 최소 1회).

## 판정 기준(BETA 출하 조건)

1. **E1에서 600초 동안 GPS 끊김 표시(회색·위성-X)가 뜨지 않고 표시 속도가 입력 속도를 따른다.** 끊김이 뜨면 정확도 필드를 지워 "GPS 끊김" 형식으로 내리는 안으로 바꾼다([결정 기록](../BETA_DECISIONS_2026-10-05.md)).
2. **E1에서 화살표가 335° 고정 방위 때문에 이상하게 움직이면**(속도>0인데 방위가 지도 도로와 어긋나 외삽 방향이 틀어지는 등) E2(방위 없음)가 더 낫다면 덮어쓰기에서 방위 필드(`hasBearing`)도 지운다.
3. E3에서 첫 fix 전환 때 지도가 따라오고 끊김이 지속되지 않아야 한다(44 m 점프는 순정과 같은 거동).
4. E5(순정)보다 나빠지는 점이 있으면(표시 속도 오류, 끊김 등) BETA의 NO_FIX 덮어쓰기를 끈다.

## 한계

폰은 실내이고 실제 GPS 세기는 측정하지 않는다. 폰 GPS가 정상일 때 네이버가 폰 GPS로 넘어가는지는 DHU에서 1회만 봤다(넘어가지 않음). 10분 이상 같은 좌표에 속도만 바꾸는 입력의 거동은 이 시험이 처음이다.
Mazda 형식(timestamp 0), 무선 동글, 실제 차속은 시험하지 않는다. 이 계획은 차량 시험이나 ASSIST 활성화를 승인하지 않는다.
