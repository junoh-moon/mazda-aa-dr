# DHU 시험 13 소유자 준비 사항

시험 13(터널 안 분기 안내 시험)은 소유자의 손이 필요 없습니다. 준비는 시험 12와 같고, 폰 설정이나 노트북 DHU 설정을 바꾸실 필요가 없습니다.
DHU는 보낸 좌표만 쓰므로 폰이 부산에 있어도 서울 경로를 시험할 수 있습니다(목적지 검색은 에이전트가 DHU 화면 키보드로 합니다).

1. **폰은 지금 그대로 두십시오.** 잠금이 풀린 상태로 USB에 연결해 두시면 됩니다. 폰을 옮기거나 GPS·위치 설정을 바꾸지 마십시오.
2. **헤드유닛 서버 켜짐.** 이미 켜져 있으면 그대로 두십시오(Android Auto 설정 → ⋮ → "헤드유닛 서버 시작").
3. **에이전트 시작.** README 맨 위 지시문의 `COMMIT_TO_PIN`을 실제 커밋으로, `SESSION_N`을 1로 바꿔 붙여 넣으십시오. 회기 2는 다른 때에
   `SESSION_N`을 2로 바꿔 붙여 넣습니다. ADB 허용 창이 뜨는 경우에만 "항상 허용" 후 허용을 누르십시오(이미 승인되어 있으면 뜨지 않습니다).

회기마다 Tier 0 시작부터 약 25분입니다(환경 2분 + Tier 0 7~8분 + 회차 약 4.5분씩). 회기 1은 R25X15 → R25X0 → R40X15, 회기 2는 M 경로 확인 뒤
R25X28 → R40X28 → R25X15 반복(→ 시간이 남으면 R40X0)입니다. 서울 경로가 준비되지 않으면 에이전트가 부산 경로로 환경만 확인하고 멈춥니다.
Tier 0 결과는 끝나는 즉시 따로 올라오고, 나머지는 끝나는 대로 올라옵니다(05:55~06:10 KST만 피함).
