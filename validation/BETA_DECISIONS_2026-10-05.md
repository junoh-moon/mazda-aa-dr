# BETA 설계 결정 갱신 — 2026-10-05 (shadow.5 자료 반영)

[설계 결정](ASSIST_BETA_DESIGN_2026-10-05.md)과 [주행 분석](TRIP_SHADOW5_2026-10-05.md), 독립 검토 두 건(OEM 경로·잘못된 위치 경로), 설계 영향 분석 두 건(Opus·Fable)을 합쳐 확정한다. 이 기록은 차량 시험이나 ASSIST 활성화를 승인하지 않는다.

## 1. 위치 상태 분류(송신 시점에 관측 가능한 것)

- **NO_FIX**: mode 1/2이고 utc_s=0(부팅 후 fix 없음, 저장값). 두 주행에서 12~15분 지속, 저장값은 부팅 사이에 바이트 단위로 같고 나이를 알 수 없다.
- **FIX**: mode 1/2이고 utc_s>0이 이전보다 증가.
- **LOST**: mode 0(fix 뒤 단절, 10-04 끝에서 관측; utc는 계속 증가, 좌표·방위·속도 동결, HDOP 99/99).
- 그 밖: mode 3, 해독 불가, utc 정체(>3초 증가 없음)는 원본 통과. 분류 키는 mode와 GetPosition의 utc_s이며 HDOP는 키가 아니다.

## 2. 처리

- **NO_FIX 구간(S1)**: 저장 위치·방위는 앵커가 될 수 없고(나이 미상, 방위 약 100° 어긋남 관측, 위치 44~195 m 어긋남) 위치·방위 치환은 금지한다. **속도만 덮어쓰기(Fable안)**: 복사본에서 바이트 32~39(`hasSpeed=1`, 속도)만 휠 속도로 바꾸고 나머지 40바이트는 원본이며 정확도 주장을 추가하지 않는다. 정지(네 바퀴 0)이면 0.
  출하 조건: 정지 좌표+정확도 8.8 m+속도 변동을 10분 이상 보낸 DHU 시험에서 네이버가 끊김 없이 속도를 표시해야 한다. 끊김이 되면 정확도 필드를 지워 "GPS 끊김" 형식으로 내리는 안(Opus안)으로 바꾼다.
  G2(방위)는 이 구간에서 달성할 수 없으며 그렇게 문서화한다.
- **LOST 구간(S3)**: 원래 설계의 DR 치환(정직한 예산 40 m, 앵커 게이트). 예산을 넘으면 원본.
- **FIX 구간**: 원본(NOT_UNKNOWN) 유지.

## 3. 앵커 게이트와 예산 수정(독립 검토 지적 반영)

1. 앵커 쌍은 utc가 이전보다 **엄격히 증가**하고(차이 ≤2초) 같은 utc는 비교 기준을 갱신하지 않는다. UTC 경과와 수신 mono 경과가 일치해야 한다.
2. HDOP ≤ 3.0 필수. 쌍 변위가 속도×dt의 [0.5, 1.5]배. 첫 fix 직후 연속 증가 fix가 10초 쌓이기 전에는 앵커 금지. GPS 복귀 직후도 같은 대기. 모든 거부 사유를 journal에 남긴다.
3. 위치 정확도에 **회전 항**을 넣는다: 위치 예산의 방위 성분을 hb(τ) = 0.03 + 0.002·τ + 0.10·누적|회전|으로 하고 ∫v·hb dτ를 쓴다(방위 20° 철회 판단은 유지).
4. 후진 래치: 래치=후진인데 휠 속도 15 km/h 초과가 2초 넘게 이어지면 철회(BETA는 앵커를 다시 받을 때까지 정지). 후진 1→0 전이를 한 번도 보지 못했으면 켜지 않는다. 래치는 모든 리셋과 REVERSE 제외 때 지운다.
5. yaw 영점은 **고정 2048**(두 주행의 정지·주행 추정 2045~2050의 중간), 정지 영점 자동 보정 금지(시동 직후 정지 영점 2037.7은 주행 최적값에서 12카운트 어긋났다). 방위 예산의 k=0.002는 ±3카운트를 덮는다.
6. 어댑터: `hold`를 세울 때 어댑터가 `invalidate()`도 한다(`allow_beta`이면 `beta_event` 필수). `DrSnapshot`의 기본값 초기화(NSDMI)를 없애고 `static_assert`로 trivial 생성을 보장한다. `choose_beta`는 UNOBSERVED를 "설치가 명시적으로 거절한 경우"에만 받는다.
7. **설치 결함**: BETA에서 세션 판독기를 바꾸면 설치기가 거부한다(실제 BLM+libpatch 0.10.0 QEMU 재현). 판독기는 항상 순정으로 두고 송신 쪽 저장소 관찰은 별도 후크(`Options.send_storage`)로 분리한다. 차량 libpatch는 0.9.1이므로 0.9.1로도 설치를 검증한다.
8. 판정 블록 버그와 로그 속도(문서 보정)는 별도로 수정한다([주행 분석](TRIP_SHADOW5_2026-10-05.md)).

## 4. 출하 전 검증

T6 재생(10-05의 191~714초 523건 전부 속도 덮어쓰기, DR 치환 0건, 727초 FIX에서 ARMED 복귀; 10-04는 mode 1에서 치환 0건, 1453초 LOST 전이와 예산 내 철회), DHU wire 시험(위 출하 조건), 결함 주입, 실제 BLM+libpatch(0.9.1과 0.10.0) QEMU, 독립 재검토.
