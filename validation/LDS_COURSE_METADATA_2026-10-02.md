# LDS course 입력 존재 정보 — 2026-10-02

이 변경은 빈 방위각 입력과 실제로 입력한 `0`을 구별할 정보를 보존합니다.
[이전 원본 실행](LDS_COURSE_PRESENCE_2026-10-02.md)에서는 빈 course도
새 heading 할당과 숫자 0으로 나타났습니다. 숫자·할당 번호만으로는 둘을
구별할 수 없으므로 `unknown`·`empty`·`present`를 별도로 기록합니다.

## 구현 범위

- 분류기는 NUL을 포함해 최대 256바이트에서 단일 RMC의 여덟 번째
  데이터 필드가 비었는지만 확인합니다. `present`는 숫자 유효성, 체크섬
  수용, 수신기 품질 또는 측정 시각의 판정이 아닙니다.
- 원본 parser 입력과 반환을 관측하고 동일 reader의 확인된 callback,
  workspace, 호출 경로와 수명에 연결합니다. 실제 캐시 복사에서 한 번만
  소비하며, 중첩·재진입·초기화·Open/Close·계수 소진은 잘못된 연결을
  `unknown`으로 만듭니다. 원본 실행과 heading 할당 마스크는 유지합니다.
- heading을 할당하지 않는 callback은 자신이 실제로 읽었던 snapshot의
  정보를 상속합니다. 다른 callback의 최신 전역 값을 가져오지 않습니다.
- 기존 640바이트 sideband의 v2와 공유 map v2에 포함해 같은 원본 응답의
  AA POSITION/SEND 소유 복사본까지 전달합니다. sideband v1은 존재 정보를
  `unknown`으로 읽습니다. map 버전 불일치는 원본 AA 송신을 막지 않습니다.
- PC 분석기는 정확한 요청·응답·payload 연결에서만 이 정보를 집계합니다.
  잘못된 보조 정보 때문에 원시 POSITION 기록을 지우지 않습니다.

## 집중 검증

구현 전 누락과 잘못된 연결을 실패하는 회귀로 보존하고, 검증용 사본의
입력 SHA를 고정했습니다. 아래 수는 각각 실제 실행 범위이며 중복 합산하지
않습니다. 전체 제품 빌드와 원본 reader→AA 실행은 별도 후속 작업입니다.

| 범위 | 실행 결과 |
| --- | --- |
| 분류기·저장 snapshot 상속 | 새 host와 고정 ARM 각각 12사례·207검사 통과 |
| producer hook | host·고정 ARM 각각 68사례 통과 |
| 원본 cold 설치기 | 고정 ARM 96사례 통과, 9개 모듈·30개 슬롯 검증 |
| 공유 map | host·ARM 각각 19사례·1,207검사 통과 |
| 요청 연결 공급부 | host·ARM 각각 14사례·416검사 통과 |
| sideband | host 391검사, ARM 235검사 통과; 압력 반복 횟수는 실행별 값 |
| journal·PC 분석 | host Python 178개 통과, ARM 새 POSITION/SEND 조합 8개 통과 |

Python 178개 첫 실행은 JSON 출력용 fixture가 일반 자기검사 안내도 먼저
출력해 1개가 실패했습니다. JSON 출력 분기를 앞당긴 fixture 수정 후 같은
178개가 통과했습니다. 제품 오류로 바꾸어 적거나 첫 실패를 삭제하지 않습니다.

실제 Claude 설계 리뷰와 테스트 작성 호출도 사용했습니다. 테스트 작성의
첫 호출은 기존 600초 제한에 걸렸습니다. 사용자 지시에 따라 제한 없이
다시 실행한 호출은 약 541초 후 정상 완료됐습니다. 제안된 테스트를 별도로
native 빌드·실행해 12,120검사를 통과했으며, 이는 반복 검사를 포함한 수입니다.
Claude 자체가 제품이나 차량을 실행한 결과가 아닙니다.

집중 빌드한 실제 LDS DSO의 정적 TLS는 기존 52바이트에서 76바이트로
24바이트 증가했습니다. 원문이나 큰 snapshot을 TLS에 저장하지 않습니다.
이 크기 확인만으로 원본 스레드의 실제 스택 여유를 입증하지 않습니다.

## 남은 범위

고정 소스 전체 검사와 여섯 제품 빌드, 새 제품을 사용하는 원본
reader→AA 통합 실행이 남아 있습니다.
통합 fixture에는 빈 course와 literal `0`, heading 미할당 시 상속, 후속
70도 입력을 포함하며 제품의 parser/select 관측 지점을 다른 시험 hook으로
덮지 않습니다. 이 문서는 새 릴리즈나 차량 설치 승인이 아닙니다.

물리 측정 시각·센서 품질·전체 SM 기동·S25/지도 수용은 미검증입니다.
live 공급부의 물리 자격과 ASSIST는 미완료이며 비활성입니다.
