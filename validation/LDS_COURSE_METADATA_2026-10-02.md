## 구현 범위

  데이터 필드가 비었는지만 확인합니다. `present`는 숫자 유효성, 체크섬
  수용, 수신기 품질 또는 측정 시각의 판정이 아닙니다.
- 원본 parser 입력과 반환을 관측하고 동일 reader의 확인된 callback,

  소비하며, 중첩·재진입·초기화·Open/Close·계수 소진은 잘못된 연결을
  `unknown`으로 만듭니다. 원본 실행과 heading 할당 마스크는 유지합니다.

  정보를 상속합니다. 다른 callback의 최신 전역 값을 가져오지 않습니다.
- 기존 640바이트 sideband의 v2와 공유 map v2에 포함해 같은 원본 응답의

  `unknown`으로 읽습니다. map 버전 불일치는 원본 AA 송신을 막지 않습니다.

## 후속 소비 경계 수정과 회귀

adapter가 공유 map의 공통 `protocol::VERSION`을 사용하도록 수정했습니다.
알 수 없는 enum과 heading 할당 출처가 없는 `empty`·`present`는 보조
정보만 충돌로 처리합니다. 원시 위치와 원본 송신 경로는 유지합니다.

- 수정 전 adapter는 `empty`·`present` 양성과 옛 v1 거부 회귀에서 각각
  실패했습니다. 버전 조건만 고친 별도 대조에서는 이 세 검사가 통과하고,
  잘못된 enum·출처 누락 회귀 두 개가 실패했습니다. 잘못된 버전 때문에
  다른 오류를 우연히 거부한 결과와 구분합니다.
- 최종 source-linked host와 고정 ARM은 각각 44사례를 생략 없이
  통과했습니다. adapter 문맥 22개, 문맥 풀 12개, 실제 runtime 연결
  10개입니다. 실제 Publisher→Registry→adapter에서 숫자 0인 `empty`와
  `present`, `unknown`을 POSITION·SEND와 journal까지 대조했습니다.
- 중첩·동시 실행·fork 문맥의 소유 사본 비교에도 존재 정보를 포함했습니다.

  확인합니다. 새 사례를 host·ARM·실제 DSO runner에 모두 연결했습니다.
- protocol header 변경 때 host adapter 검사도 다시 빌드되도록 의존성을
