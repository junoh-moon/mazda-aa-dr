# 네이버 지도 판단 기록 도우미 (2026-10-13)

폰에 닿는 곳은 소유자의 Mac(adb)뿐입니다. 근거는 `validation/NAVER_MAP_LOGGING_2026-10-13.md`입니다. **네이버 지도 앱을 수정하지 않고** 개발용 설정 파일 `navi.config`에 `trace=1` 한 줄만 넣어, 앱이 자기 판단(차↔폰 전환, 점프 R1/R2, 무효, 회색, 가상주행)과 입력 위치마다의 기록을 파일로 남기게 합니다.

1. `sh check.sh` — **읽기 전용**. 접근 가능 여부, 설치 버전(6.10.0.16이어야 분석과 가장 가깝습니다), 기존 설정을 봅니다. 폰은 바뀌지 않습니다.
2. `sh enable.sh` — `yes`를 입력해야 실행됩니다. `navi.config`에 `trace=1` 한 줄을 씁니다(기존 파일은 `.bak`로 보존). 네이버 지도의 안내를 한 번 다시 시작해야 읽습니다.
3. 주행 또는 DHU 시험.
4. `sh collect.sh` — 로그를 가져와 zip으로 묶습니다(`--clear`를 주면 폰의 로그를 지움). 안내된 `curl --upload-file`로 올려 주십시오.
5. 끝나면 `sh disable.sh` — 설정 파일을 지우거나 원래대로 되돌립니다.

주의: 로그에는 **정밀 좌표**가 들어갑니다(공유하지 마십시오). 크기 제한이 없어 오래 켜 두면 수십 MB가 될 수 있습니다. `ignore_input_location` 같은 다른 키는 **절대 넣지 마십시오**(모든 입력 위치가 버려집니다). 안드로이드 15/16에서 `adb`가 `Android/data`에 접근하는지는 확인되지 않았으므로 1번이 실패하면 멈추고 알려 주십시오.
