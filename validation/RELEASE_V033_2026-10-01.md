# v0.3.3-shadow.1 설치 ZIP 검증

대상은 1세대 Mazda Connect NA 74.00.324A입니다. 이 pre-release는 SHADOW
시험 후보입니다. 순정 위치 송신을 유지하고 MODEL 위치는 기록만 합니다.
ASSIST는 비활성이며 차량·물리 센서·폰 수용을 검증한 v1.0이 아닙니다.

## 공개 산출물

- 태그: [`v0.3.3-shadow.1`](https://github.com/junoh-moon/mazda-aa-dr/releases/tag/v0.3.3-shadow.1), 공개 pre-release
- 주석 태그가 가리키는 고정 커밋: `260528c751739c0afb59153f7a5cfa3585eb6048`
- 설치 파일: `mazda-aa-dr-v0.3.3-shadow.1.zip` (1,423,003 bytes)
- ZIP SHA-256: `efb19668f1ecba06176ff8ad5ddfab4302bccd2fc0637291aff5e89b9ce72ba1`
- 체크섬 파일: `mazda-aa-dr-v0.3.3-shadow.1.zip.sha256`
- 기본 모드: SHADOW. `bundle-default-mode`·`build-info.json`이 일치하며
  `source_modified=false`입니다.

2026-10-01에 게시된 두 파일을 다시 받았습니다. ZIP과 체크섬 파일은 게시 전
파일과 각각 바이트 단위로 같았습니다. 공개 ZIP의 SHA-256·CRC와 주석 태그의
peeled commit도 위 값과 일치했습니다. GitHub의 자동 Source code ZIP은
설치 묶음이 아닙니다.

## 배포 파일과 직접 검사

SSH로 받은 별도 깨끗한 checkout에서 고정 GCC 4.9.1 ARMv7 Cortex-A9 NEON
softfp 도구체인(upstream `61ec0343de84f6fc7c46840056df1d600d44be8a`)으로
다섯 파일을 새로 빌드했습니다. 모두 ELF32 ARM이며 `GLIBC_2.4`만 요구합니다.
TEXTREL·RPATH·RUNPATH·동적 libstdc++ 의존성은 확인되지 않았습니다.
ZIP에서 꺼낸 파일은 빌드 산출물과 바이트 단위로 일치합니다.

1. 최종 ZIP의 파일과 원본 펌웨어 fixture를 지정한 Debian 12 `make test`가
   종료 0·skip 0으로 통과했습니다. Python 350개(빌드 41, motion 94,
   recovery 28, loader 1, collector 10, packaging 144, tools 32)와 C/C++
   검사를 포함합니다. 호스트와 ARM을 순차 실행했습니다.
2. 동일한 다섯 파일의 고정 ARM/QEMU 전체 검사가 종료 0·skip 0으로
   통과했습니다. 시작·끝 `ARM_TEST_INPUTS`의 `release_verified=true`,
   도구체인·sysroot·다섯 해시가 일치했습니다. navigation 2,740,
   bias 2,677, GPS/wheel 84,601, holdout 5,443 합성 검사와 실제 배포 DSO의
   position/request/session/bus 검사를 포함합니다.
3. ZIP 35개 파일의 CRC·전체 `SHA256SUMS`를 확인했습니다. 최상위에
   `install.sh`, `mp3/`, `js/`가 있고 정적 ARM 해시 도구를 포함합니다.
4. 원본 ARM BusyBox 1.19.2 `awk`로 상태 표시 30개를 통과했습니다.
   최종 ZIP을 푼 묶음을 원본 BusyBox/libc 격리 chroot에서 설치·loader·
   일회 기동·collector UID/종료·주차 중 상태/종료/회수·touch 변경 후
   재예약·제거·재설치까지 실행했습니다. 손상 USB 거부도 확인했습니다.
   마운트와 센서 상태 행은 합성 fixture입니다.

이번 변경은 초기화 직후 정상 raw가 상태를 덮어도 주 MODEL fault 사유를
남기고, 해당 raw를 원인 진단보다 먼저 기록합니다. 주차 상태와 PC 분석에
실제 `drain()` 호출 수와 초기화 사유를 표시합니다. [원인 재현과 검토](MODEL_RESET_REVIEW_2026-10-01.md)에
수정 전 실패 및 수정 후 검사를 남겼습니다. Claude Code CLI의 diff 검토는
시간 제한 안에 결과가 없어 독립 리뷰 통과로 세지 않았습니다. 외부
`feat/session-observation`의 고정 8 MiB 공간 임계값은 이번 ZIP에 없습니다.

## 미검증 범위

이번 고정 ZIP으로 원본 OEM 서비스 전체를 새로 기동하지 않았습니다.
마운트 에뮬레이션과 합성 ARM 실행은 물리 차량의 저장소 여유·센서
측정 시각/품질, 정상 전체 기동·복구, Galaxy S25·무선 AA·네이버 지도
수용이나 터널 위치 정확도의 근거가 아닙니다. 원본 LDS 진단과 각 위치
응답에 동일한 생산 측정 ID가 없어 ASSIST 자격 연결도 미완료입니다.
원본 바이너리·주소 지도·개인 공유 링크·차량 로그는 공개하지 않습니다.
