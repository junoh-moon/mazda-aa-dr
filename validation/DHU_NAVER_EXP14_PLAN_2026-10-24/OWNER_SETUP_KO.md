# DHU 시험 14 소유자 준비 사항

시험 14(G3 이월 방위·TAN 해제 점프의 화면 효과)는 소유자의 손이 필요 없습니다. 준비는 시험 13과 같습니다.

1. **폰은 지금 그대로 두십시오.** 잠금이 풀린 상태로 USB에 연결해 두시면 됩니다. 폰을 옮기거나 GPS·위치 설정을 바꾸지 마십시오.
2. **헤드유닛 서버 켜짐.** 이미 켜져 있으면 그대로 두십시오(Android Auto 설정 → ⋮ → "헤드유닛 서버 시작").
3. **에이전트 시작.** README 맨 위 지시문의 `COMMIT_TO_PIN`을 실제 커밋으로, `SESSION_N`을 1로 바꿔 붙여 넣으십시오. 회기 2는 다른 때에
   `SESSION_N`을 2로 바꿔 붙여 넣습니다. ADB 허용 창이 뜨는 경우에만 "항상 허용" 후 허용을 누르십시오(이미 승인되어 있으면 뜨지 않습니다).

회기마다 Tier 0 시작부터 약 20분입니다(환경 2분 + Tier 0 7~8분 + 회차 약 2.5분씩 4회). 회기 1은 방위 4회(G0 → G37 → G84 → G171),
회기 2는 점프 4회(J0 → J15 → J37 → J113)입니다. 같은 경로(서울 신월여의지하도로)를 쓰므로 회기 사이에 설정을 바꾸실 것은 없습니다.
결과는 끝나는 즉시 따로 올라옵니다(05:55~06:10 KST만 피함).
