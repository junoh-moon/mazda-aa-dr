# 한 줄 OBSERVE 설치 — draft

기존 root 접속으로 CMU에 들어가 **설치 ZIP을 푼 폴더**에서 실행한다.

```sh
sh ./install.sh
```

명령이 성공하면 정상적으로 전원을 껐다 켠다. 다음 가드 경유 부팅에 한해
OBSERVE와 collector가 자동으로 시작한다. 설치기가 CMU를 강제 재부팅하거나
AA를 중간에 종료하지는 않는다. 실제 차량에서 첫 부팅과 기존 AA·터치가
정상인지는 주차 상태에서 확인한다. 이후 관찰·로그 회수 절차는
[첫 시험 안내](FIRST_TRIAL_KO.md)를 따른다.

설치기가 자동으로 처리하는 것은 다음과 같다.

- 기본 OBSERVE 선택, 펌웨어/지역/원본 해시·ARM 바이너리와 체크섬 검사.
- 패키지에 `SHA256SUMS`가 있으면 전체 묶음 검사. 별도 검사 명령 불필요.
- 필요한 읽기 전용 마운트만 임시 쓰기 가능으로 전환. 성공/실패 종료 시 복원.
- 기존 touch 토큰 보존, 백업·가드 설치, 한 번의 시험 부팅 예약.

이 변경은 **명령 입력을 줄인다**. root 접근·해당 펌웨어 요구·기존 설치 충돌
검사를 없애거나 ASSIST를 켜지 않는다. 구버전 영구 mx5dr preload가 있으면
기존처럼 먼저 제거를 요구한다. 기존 터치 패치를 제거할 필요는 없다.
읽기 전용 상태를 변경하지 않도록 강제하려면 `--no-remount`를 쓸 수 있으며,
과거 `--remount` 옵션도 호환된다. fixture 모드에서는 자동 remount를 하지 않고
명시적인 `--remount`도 계속 거부한다.

공개된 `v0.2.0-observe.1` ZIP은 이 변경 전이다. 해당 ZIP을 그대로 쓴다면
`sh ./install.sh --remount`가 한 줄 설치 명령이다. OBSERVE는 이미 기본값이고
바이너리·펌웨어 검사는 이미 설치기 안에서 수행한다. 현재 draft가 병합되어
새 패키지로 배포된 뒤부터 옵션 없이 `sh ./install.sh`를 안내할 수 있다.

전체 체크섬은 손상 검사용이며 신뢰할 수 없는 설치 코드를 인증하는 서명이
아니다. 이미 실행한 shell 스크립트를 그 스크립트 자체의 검사로 인증한다고
주장하지 않는다. 전원 단절과 SIGKILL은 shell exit trap의 보장 밖이며 실제
다음 부팅 복구 범위는 기존 가드 문서를 따른다.
