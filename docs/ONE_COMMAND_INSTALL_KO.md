# USB 숫자 메뉴로 설치·CMU 재부팅·회수

대상은 **2019 MX-5 ND2 6MT / Mazda Connect NA 74.00.324A**입니다.
현재 공개판은 [v0.3.9-shadow.2](https://github.com/junoh-moon/mazda-aa-dr/releases/tag/v0.3.9-shadow.2)이며,
설치 파일 `mazda-aa-dr-v0.3.9-shadow.2.zip`의 SHA-256은
`4f6633ac95a20aa6c9907c2938843dff2fa769e6fd4c14dbc4fc243d7bf30699`입니다.
GitHub의 자동 `Source code (zip)`은 설치 ZIP이 아닙니다.

**아래 `1 → 5 → 2 → 0`과 확대 회수는 다음 릴리즈 후보의 절차입니다.**
공개 `.2`에는 메뉴 `5`와 새 부팅 대조·전체 설치 폴더 회수가 없습니다.
새 버전의 고정·검증·발행이 완료되기 전 공개 `.2`에 이 절차를 적용하지 마십시오.
첫 실차 회수 archive에는 trace·collector 기록이 없었습니다.
[빈 기록 분석](../validation/FIELD_V039_EMPTY_CAPTURE_2026-10-02.md)을 보존하며,
지금 추가 방문·재설치·재주행을 요청하지 않습니다.

기존 `/proc/mounts` 회수 오류만 해결할 때는 공개 `.2`의 한 줄과 `3`을
사용합니다. 이미 제거했어도 남은 파일은 회수하지만, 기록이 없던 구간을
복원하거나 같은 주행을 반복할 이유가 되지는 않습니다.

ZIP의 **내용물 전체**를 깨끗한 FAT32 USB 최상위에 복사하여 `trial`,
`install.sh`, `mp3/`, `js/`가 바로 보이게 하십시오. 기존 USB 결과는 PC에
먼저 보관하십시오. USB 포트 하나를 설치·회수용 USB와 무선 AA 동글이
번갈아 사용하며 허브나 동시 연결은 요구하지 않습니다.

ACC와 엔진이 꺼진 ON은 실제 엔진 가동과 다릅니다. 둘 다 시동 버튼의
주황 표시등이 켜집니다. 실제 엔진 가동도 ON이지만 주황 표시등은
꺼집니다. [공식 전원 상태 설명](https://www.mazdausa.com/static/manuals/2019/mx5/contents/05010101.html)을
참고하고, **타코미터가 0보다 높은 실제 엔진 가동**을 확인하십시오.
이 프로젝트는 설치·재부팅·확인 동안 전원을 일정하게 유지하기 위해 그 상태를
사용합니다. Mazda의 패키지 승인이나 ACC에서의 설치 검증을 뜻하지 않습니다.

1. 배기가스가 쌓이지 않는 환기되는 장소에 주차하고 주차브레이크를 채우십시오.
   **6MT 기어를 중립 N에 두고 브레이크와 클러치를 끝까지 밟은 상태에서 시동
   버튼을 눌러 엔진을 켜십시오.** 시동이 완전히 걸릴 때까지 페달을 밟고,
   아래 확인까지 중립·주차브레이크·공회전을 유지하십시오.
   [공식 시동 설명](https://www.mazdausa.com/static/manuals/2019/mx5/contents/05010200.html)을 따르십시오.
2. 설치 USB를 연결하고 기존 MP3 셸 진입 방식으로 셸을 여십시오.
   다음 한 줄을 입력하고, 최초 설치에만 **`1`과 Enter**를 누르십시오.

   ```sh
   sh /tmp/mnt/sda1/trial
   ```

   USB가 sdb1 등으로 잡히면 해당 글자만 바꾸십시오. Shift 입력이나 수동
   `mount`, `chmod`, `chown`, 해시 명령은 필요하지 않습니다.
3. 설치 완료 뒤 같은 메뉴에서 **`5`와 Enter**를 누르십시오. USB 요청 기록의
   저장·동기화와 필요한 읽기 전용 복원 후 순정 `/sbin/reboot`를 옵션 없이
   요청합니다. **시동 버튼을 누르지 말고 엔진과 USB 연결을 그대로 유지하십시오.**
   차량 시동 OFF/ON은 이 CMU 재부팅을 대신하지 않습니다.
4. CMU 화면이 돌아오면 같은 USB의 MP3로 셸을 다시 열고, 같은 한 줄 뒤
   **`2`와 Enter**를 누르십시오. 다음 네 줄을 각각 확인하십시오.

   - `reboot_check=new_boot_observed`
   - `one_boot=consumed_this_boot`
   - `retained_bytes`가 0보다 큼
   - `collector_poll_recent=observed`

   AA가 없어도 collector는 기동할 수 있습니다. 모든 센서 수신이나 전체
   `status_exit=0`을 요구하지 않으며, 정차·AA 분리로 종료 코드가 1일 수 있습니다.
   네 근거 중 하나라도 없으면 이동하지 말고 `3`으로 자료를 회수하십시오.
   메뉴 종료 후 같은 한 줄로 돌아와 `4`로 예약을 해제하고, 임의로 재설치하지 마십시오.
5. 확인됐으면 **`0`으로 메뉴를 끝내고 USB를 뺀 뒤 무선 AA 동글을 연결하십시오.**
   시동이나 CMU를 다시 재부팅하지 말고, 기존 AA·터치를 주차 중 확인하십시오.
   `2`는 조회 명령이며 수집은 선택된 부팅에 자동으로 시작됩니다.

별도로 정한 시험이 끝나면 주차한 뒤 AA를 분리하고 같은 USB를 연결하십시오.
MP3 셸에서 같은 한 줄 뒤 바로 **`3`과 Enter**로 종료·회수하십시오. 가능한 경우
같은 부팅에서 회수하되, 셸 복귀에 새 CMU 부팅이 필요해도 보존된 이전 자료를
회수할 수 있습니다. 다시 `1`을 누르거나 재무장하지 마십시오.

회수에는 `mx5-aa-dr` 설치 폴더 전체, 실제 autostart·SM 파일, 용량을 제한한
현재 부팅의 `/proc`·명령 출력·재부팅 요청 기록이 포함됩니다. 진단 일부가 없거나
잘려도 보존 원시 자료의 회수를 계속합니다. 현재 종료 확인의 `finish_exit`와
자료 회수의 `export_exit`를 구분하십시오. `export_exit=0`은 확보 가능한 자료의
회수 성공이며, 정상 수집·계산이나 재부팅 완료를 뜻하지 않습니다.

USB의 archive·`.sha256`·결과 텍스트를 함께 비공개로 보관하십시오. tar 실패로
남은 `.partial`과 USB 진단 폴더도 버리지 마십시오. archive와 진단 임시 파일은
USB에 만들며 차량에는 원래 로그를 보존합니다. 재부팅 전 마지막 기록이나
이미 회전으로 사라진 자료까지 복원하지는 못합니다. `4`는 제거이며 로그를 남깁니다.
운전 중에는 명령을 입력하거나 USB를 바꾸지 마십시오.

[상세 USB 안내](../packaging/USB_START_KO.md)와 [통합 시험 절차](FIELD_TRIAL_KO.md)를
따르십시오. 실제 기동·센서·물리 복구·폰 수용은 미검증이며 live ASSIST는
계속 비활성입니다. v1.0의 관성항법 실제 적용 목표는 아직 완료되지 않았습니다.
