# USB 숫자 메뉴로 설치·시험·회수

현재 공개 파일은 NA 74.00.324A 전용
[v0.3.9-shadow.2 설치 ZIP](https://github.com/junoh-moon/mazda-aa-dr/releases/tag/v0.3.9-shadow.2)입니다.
파일명은 `mazda-aa-dr-v0.3.9-shadow.2.zip`이고, SHA-256은
`4f6633ac95a20aa6c9907c2938843dff2fa769e6fd4c14dbc4fc243d7bf30699`입니다.
GitHub의 자동 `Source code (zip)` 대신 이 설치 ZIP을 받으십시오.

**이전 회수가 `/proc/mounts` 오류로 실패했다면:** USB에 기존 결과가 있을 경우
PC에 먼저 보관하고 핫픽스 내용물로 교체하십시오. 아래 한 줄 뒤 **`3`과 Enter만**
누르십시오. `4`로 제거한 뒤에도 남은 로그를 회수합니다. 재설치·재주행은
필요하지 않으며 현재 종료 확인 실패와 `export_exit=0`의 회수 성공은 구분합니다.

이번 실차에서는 핫픽스로 회수한 archive에 수집 기록이 없었습니다.
[기동·저장 경로 조사](../validation/EMPTY_CAPTURE_2026-10-02.md)를 진행 중이며,
같은 주행을 반복하거나 재설치할 단계가 아닙니다.

ZIP의 **내용물 전체**를 깨끗한 FAT32 USB 최상위에 풀어 복사하십시오.
USB에서 `install.sh`, `mp3/`, `js/`, `trial`이 바로 보여야 합니다.
차량의 USB 포트 하나를 설치·회수용 USB와 AA 연결이 번갈아 사용합니다.
주차 중 Entertainment → USB에서 포함된 곡을 재생하고 진단 셸이 열리면
다음 한 줄로 메뉴를 열고 최초 설치에만 `1`과 Enter를 누르십시오. 실제 USB가 sdb1 등으로
잡히면 경로만 바꾸십시오. Shift 입력은 필요하지 않습니다.

```sh
sh /tmp/mnt/sda1/trial
```

설치 명령이 성공하면 셸 사용을 마치고 USB를 분리한 뒤 유선 AA를 연결하십시오.
정상적으로 전원을 끄고 다시 켜면 다음 **한 번의 부팅**에서 SHADOW 관측·계산·
기록이 차량 내부 파일로 자동 실행됩니다. 메뉴 `2`는 선택 진단이며 기동 조건이
아닙니다. AA·터치의 정상 동작은 주차 중 화면으로 확인하십시오. ASSIST 송신은
비활성입니다. 별도 `sha256sum`, 계정 이름 `root`, 수동 remount 명령은
필요하지 않습니다. 설치기는 기존 터치·km/L 설정을 보존합니다.

시험 후 주차한 다음 AA를 분리하고 같은 USB를 연결하십시오. 셸로 돌아와
위 한 줄로 메뉴를 열고 바로 `3`과 Enter로 자료를 회수하십시오. 셸 복귀에
정상 재부팅이 필요하면 재부팅 후에도 남아 있는 이전 시험 로그를 회수할 수
있습니다. 재설치나 재무장은 하지 마십시오. 가능한 경우 같은 부팅에서 회수하되,
재부팅 전 마지막 기록의 저장이나 이미 회전된 자료까지 보장하지는 않습니다.

AA 분리·재부팅 뒤의 현재 상태와 이전 시험 기록은 별도로 표시합니다.
현재 부팅의 종료 확인(`finish_exit`)이 실패해도 보존 자료의 회수(`export_exit`)는
계속하며, 결과와 archive·`.sha256`을 함께 가져오십시오. 회수 성공이 정상 종료나
시험 성공을 뜻하지는 않습니다. `4`는 제거이며 기존 로그를 보존합니다.
운전 중에는 명령을 입력하거나 USB를 바꾸지 마십시오.

[회수 핫픽스 검증](../validation/TRIAL_EXPORT_HOTFIX_2026-10-02.md)을 따르십시오.
