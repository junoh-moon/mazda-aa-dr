# 05 문제가 생겼을 때

모든 조치는 주차 중에, 숫자 메뉴로만 합니다. 확실하지 않으면 **순정으로 되돌리기**(`4` → `5` → `2`가 `STOCK`)가 언제나 안전한 답입니다.

## 증상 → 할 일

| 증상 | 할 일 |
| --- | --- |
| AA가 자꾸 끊기거나, 지도가 멈추거나, 터치·HUD·km/L가 이상함 | 주차 → (로그가 필요하면 `3` → 메뉴 다시 열기) → `4` → 메뉴 다시 열기 → `5` → `2`가 `STOCK` |
| CMU가 운행 중 스스로 재부팅됨 | 다음 주차 때 `2`. `NO-GO: tripped`면 이미 순정입니다(아래 "자동 차단") |
| 메뉴 `1`이 `Install lock present`로 멈춤 | `4` → 메뉴 다시 열기 → `1` → `5` → `2` |
| 메뉴 `1`이 `Incomplete transaction`으로 멈춤 | 위와 같음: `4` → `1` → `5` → `2` |
| 설치 중 전원이 꺼짐 | 위와 같음. `4`가 `Removed an install lock left by an interrupted run.`을 보이면 정상 회수입니다 |
| `4` 끝에 `Recovered an interrupted run: choose 5, or 1 to install again.` | 그대로 `5`(순정), 또는 `1` → `5` → `2`(다시 설치) |
| 메뉴 2에 `NO   BOOT  stock this boot (...)` | 이 부팅은 가드가 순정을 골랐습니다. 다음 시동에도 같으면 `1` → `5` → `2` |
| 메뉴 2에 `BT fallback ...: menu 1` | 직접 켠 폰 블루투스 채널이 스스로 꺼졌습니다. 그대로 써도 됩니다. 끄려면 `11`, `11` → `5` |
| 메뉴 `6`이 `Refused, nothing deleted` | `4` → `5` 뒤 다시 `6`, `6` |
| 메뉴 3 뒤 운행에서 제품이 안 켜진 것 같음 | 메뉴 3 뒤 `5`를 잊은 경우입니다. 다음 시동부터 다시 켜집니다 |

## 자동 차단 (`NO-GO: tripped, stock runs, BETA off.`)

가드는 매 부팅 다음을 봅니다. 하나라도 해당하면 다음 부팅부터 **순정만** 실행하고 로그는 지우지 않습니다.

- 마지막으로 확인된 제품 부팅 이후 CMU 리셋으로 끝난 제품 부팅이 **두 번**(연달아일 필요는 없음).
- 최근 10번 중 리셋 3번, 또는 확인되지 않은 부팅(약 90초 전에 시동을 끔 등) 3번 연속.
- 설치 뒤 **첫** 부팅이 확인되지 않음(`PERSIST tripped (probation)`).

할 일: 원하면 `3`(그다음 `5`)으로 로그를 저장합니다. 계속 쓰려면 `1` → `5` → `2`, 그만 쓰려면 `4` → `5` → `2`. 짧은 운행이 이어져 생긴 차단이면 `1`로 다시 켜도 됩니다.

가드가 보지 못하는 것: 리셋 없이 생기는 이상(AA 끊김, 지도 멈춤, 터치·HUD 이상)입니다. 그런 증상은 위 표대로 직접 `4`를 하십시오.

## 원하면 남길 수 있는 것 (요청이 아닙니다)

추가 확인·주행·로그 전달을 요청하지 않으며, v1.0.0은 그런 확인을 전제로 하지 않습니다. 나중에 누군가에게 상황을 설명하고 싶을 때만 아래를 쓰십시오.

- 메뉴 2 화면 사진, USB의 `startup-result.txt`, `trial-result.txt`(상태 요약이며 위치 좌표를 출력하지 않습니다).
- `mx5dr-logs-...tar`는 정밀한 위치 이력이 들어 있으므로 믿는 사람에게만, 비공개로 전합니다.
