# 01 설치 (v1.0.0)

입력하는 것은 아래 한 줄과 숫자뿐입니다(소문자·숫자·공백·슬래시, Shift와 밑줄 없음).

```sh
sh /tmp/mnt/sda1/trial
```

USB가 `sdb1`로 잡히는 차에서는 `sda1`의 `a`만 `b`로 바꿉니다. 이하 "메뉴를 엽니다"는 이 한 줄을 입력한다는 뜻입니다.

## 준비 (집이나 PC에서)

1. 릴리스 페이지의 ZIP을 받아 풉니다. 풀린 **내용물 전체**를 FAT32 USB 최상위에 복사합니다.
2. USB 최상위에 `trial`, `mp3`, `js`가 바로 보여야 합니다.

## 설치 (주차 중, 약 5분)

1. 환기되는 곳에 주차하고 주차브레이크를 겁니다. **엔진을 실제로 켜 둡니다**(ACC나 엔진이 꺼진 ON 상태가 아님). 끝날 때까지 시동 버튼을 누르지 않습니다.
2. USB를 꽂고 Entertainment → USB에서 곡을 재생한 뒤 약 15초 기다립니다(셸 화면이 열립니다).
3. 메뉴를 엽니다. 첫 화면에 `This USB installs mode BETA`가 보여야 합니다. **BETA가 아니면 여기서 멈추고 `0`을 누릅니다.**
4. `1` → 화면 끝에 `Installation finished`가 나오면 `5`(CMU 재부팅).
5. 화면이 돌아오면 2번처럼 곡을 재생하고 메뉴를 다시 연 뒤 `2`.
6. 마지막 줄이 **`GO`**이고 **`ok   CONF  confirmed`** 줄이 있으면 설치가 끝난 것입니다.
   - `WAIT 60 s, then run 2 again`이면 60초 기다린 뒤 `2`를 다시 누릅니다.
   - 그 밖의 결과는 [02 점검](02_CHECK_KO.md)을 보십시오.
7. `0`으로 나가 USB를 빼고 AA 동글(또는 AA 케이블)을 연결합니다. USB와 AA는 동시에 꽂을 수 없습니다.

**설치 뒤 첫 부팅은 반드시 확인돼야 합니다.** `5` 뒤 `ok   CONF  confirmed`가 보일 때까지(약 2분) 시동을 유지하십시오. 그 전에 시동을 끄면 안전을 위해 제품이 스스로 꺼집니다(`PERSIST tripped (probation)`). 그때는 같은 순서(`1` → `5` → `2`)로 다시 하면 됩니다.

## 설치하면 바뀌는 것

- 매 부팅 스스로 켜집니다. 주행 중에 할 일은 없습니다.
- 순정이 GPS를 잃은 동안(터널·지하)에만 안드로이드 오토로 가는 위치·속도를 바꿔 보냅니다. 그 밖에는 순정 그대로 전달합니다.
- 실험 기능 두 개(메뉴 `11` 폰 블루투스, `12` 지하 출구 방위)는 설치할 때마다 **꺼짐**으로 시작합니다. 설치 화면 끝의 `Experimental features are OFF`가 그 뜻입니다.
- 순정 서비스 설정·블루투스 설정 파일은 고치지 않습니다. 기존 AA 터치·km/L 패치는 그대로 둡니다.

## 하지 말 것

- 운전 중에 USB 메뉴를 쓰지 않습니다. 모든 메뉴는 주차 중에만 씁니다.
- `mx5dr.conf` 같은 설정 파일을 손으로 고치지 않습니다(고치면 가드가 제품 전체를 거절합니다).
- v1.0.0은 터널 길안내와 지하 출구 방위 문제가 해결됐다는 증거가 아닙니다. 지금까지의 동작을 안전하게 쓰고 언제든 되돌릴 수 있게 만든 판입니다.
