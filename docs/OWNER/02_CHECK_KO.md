# 02 점검 — 메뉴 2 읽는 법

주차 중 메뉴를 열고 `2`를 누릅니다. 화면은 바뀌지 않고 USB에 `startup-result.txt`가 저장됩니다. 차는 제품이 꺼졌는지 알려 주지 않으므로 **몇 번 운행할 때마다 한 번** 확인하면 좋습니다.

`---- GO / NO-GO ----` 아래 줄은 `ok`(충족), `NO`(불충족), `wait`(아직 시작 중)로 시작합니다. 판단은 **마지막 줄**로 합니다.

| 마지막 줄 | 뜻 | 할 일 |
| --- | --- | --- |
| `GO` | 제품이 이 부팅에서 켜져 정상입니다 | 없음. `0`으로 나갑니다 |
| `WAIT 60 s, then run 2 again` | 아직 시작 중입니다(`wait` 줄이 있음) | 60초 뒤 `2`를 다시. 서너 번 반복해도 WAIT이면 [05](05_TROUBLE_KO.md) |
| `NO-GO` | `NO` 줄이 있습니다. 이 부팅은 제품이 꺼져 있거나 덜 준비됐습니다 | 아래 표에서 `NO` 줄을 찾습니다 |
| `NO-GO: tripped, stock runs, BETA off.` | 자동 차단: 가드가 순정으로 되돌려 매 부팅 순정만 실행합니다 | 급하지 않습니다(이미 순정). [05](05_TROUBLE_KO.md)의 "자동 차단" |
| `WAIT choose 5, then run 2 again` + `reboot pending` | 제거(`4`) 직후, 제품이 이번 부팅에서 아직 메모리에 있습니다(새 교체는 이미 멈췄습니다) | `5`로 재부팅한 뒤 다시 열어 `2` |
| `STOCK` | 제거된 상태입니다(`ok   BOOT  stock this boot`, `Product is off; stock runs.`) | 제거(`4` → `5`) 뒤라면 정상. 다시 켜려면 `1` → `5` → `2` |

## 자주 보는 `NO` 줄

| 줄 | 뜻 | 할 일 |
| --- | --- | --- |
| `NO   BOOT  installed; choose 5` | 설치는 됐고 아직 재부팅 전입니다 | `5` |
| `NO   BOOT  stock this boot (...)` | 가드가 이 부팅은 순정을 골랐습니다. 괄호가 이유입니다 | 이유를 사진으로 남기고 [05](05_TROUBLE_KO.md) |
| `NO   MODE  ...` | 설치된 모드가 BETA가 아닙니다 | `1` → `5` → `2` |
| `NO   STOP  ...` | 제품이 스스로 꺼짐 표식을 남겼습니다 | `3`으로 로그를 저장한 뒤 `1` → `5` → `2` |

## 기능 줄 (판정 조건 아님)

| 줄 | 뜻 |
| --- | --- |
| `EXP none (11, 12 off)` | 실험 기능 두 개가 모두 꺼짐(기본값) |
| `EXP ON: 11 phone bt` / `EXP ON: 12 garage` | 그 실험 기능을 직접 켜 둔 상태입니다. 끄려면 같은 번호를 두 번, 그다음 `5` |
| `CAP 25 m tunnel cap OFF (menu 10)` | 메뉴 `10`으로 터널 25 m 상한을 끈 상태입니다(이전 40 m 동작) |
| `MAP tunnel map OFF (menu 13)` | 메뉴 `13`으로 터널 지도 구속을 끈 상태입니다(BETA 전용, 일반 죽은계산). 메뉴 1 재설치와 메뉴 4 제거가 표식을 지웁니다 |
| `MAP no tunnel db` | BETA인데 `tunnels-v1.bin`이 없습니다. 지도 구속 없이 일반 죽은계산으로 동작합니다. 메뉴 1로 다시 설치하십시오 |
| `BT fallback ...: menu 1` | 켜 둔 폰 블루투스 채널이 스스로 꺼졌습니다. 순정 블루투스로 동작합니다 |

## 알아 둘 것

- 메뉴 2는 아무것도 바꾸지 않습니다. 몇 번 눌러도 됩니다.
- 메뉴 `7`, `8`, `10`, `11`, `12`, `13`으로 바꾼 설정은 `5`로 재부팅한 뒤부터 적용됩니다. 재부팅 전의 메뉴 2는 이전 상태를 보여 줍니다. `13`은 BETA 묶음에서만 보입니다.
- 메뉴 `4`(제거)는 로그·백업·프로그램 파일과 함께 약 1 MiB의 `tunnels-v1.bin`도 남깁니다. 흔적까지 지우려면 `6`, `6`을 하십시오.
- 설치 안내대로 AA를 연결하기 전, 셸 상태에서 `GO`를 확인합니다. 메뉴 2를 위해 AA를 연결해 둘 필요는 없습니다.
