# 04 되돌리기·제거

언제든 숫자 메뉴만으로 순정으로 돌아갈 수 있습니다. 순정 서비스 설정은 처음부터 고치지 않으므로 "복원"할 것이 없고, 이 묶음이 넣은 것만 뺍니다.

## 순정으로 되돌리기 (권장: 4 → 5 → 2)

1. (로그가 필요하면 먼저 [03](03_EXPORT_KO.md)의 `3` → `5`.)
2. 메뉴를 열고 `4`. 메뉴가 저절로 닫힙니다.
3. 메뉴를 다시 열고 `5`(CMU 재부팅). **4만 하고 5를 안 하면 그 부팅 동안은 제품이 아직 떠 있습니다.**
4. 재부팅 뒤 메뉴를 열고 `2`. (`4` 직후 `2`는 `reboot pending`이 보이며, 이때도 새 교체는 이미 멈춰 있습니다.) 마지막 줄이 **`STOCK`**이고 `ok   BOOT  stock this boot`가 보이면 순정입니다.

`4`는 시작 스크립트에서 이 묶음의 블록 두 개를 빼고, 매 부팅 켜기 설정과 메뉴 7~12의 표식을 지웁니다. 로그·백업·프로그램 파일은 남깁니다(다음 단계에서 지울 수 있음).

## 흔적까지 모두 지우기 (6, 6)

위의 `4` → `5` → `2`(`STOCK`) 뒤에만 합니다.

1. 메뉴를 열고 `6`.
2. `Menu 6 deletes the collected logs too.`가 나오면 `6`을 한 번 더. 다른 것을 입력하면 취소됩니다.
3. `---- DELETE RESULT ----` 아래에 `Package directory absent`가 나오면 끝입니다. 보통 `OEM files: identical to pre-install`(순정 파일이 설치 전과 같음)도 함께 나옵니다. USB에 `purge-result.txt`가 남습니다.

`Refused, nothing deleted: ... run 4, then 5, first`가 나오면 아무것도 지워지지 않은 것입니다. `4` → `5` 뒤 다시 `6`, `6`을 하십시오.

## 다시 켜기

메뉴를 열고 `1` → `5` → `2`(`GO`). 실험 기능 11·12는 다시 꺼짐으로 시작합니다.

## 이전 판 ZIP으로 돌아가기 (권장하지 않음)

순정으로 되돌리기(`4` → `5` → `2`)가 가장 안전합니다. 굳이 이전 ZIP을 쓰면 다음을 알아 두십시오.

- **beta.17 이하 ZIP의 `1`은 실험 기능(11, 12)을 저절로 켭니다**(그 판의 기본값이 켜짐이었습니다).
- 그런 ZIP으로 `1`을 했다면 `5` 전에 `11`, `11`, `12`, `12`를 입력해 끈 뒤 `5`를 누르십시오.
- 어느 판인지는 릴리스 페이지의 ZIP SHA-256으로 확인합니다.
