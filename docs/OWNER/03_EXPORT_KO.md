# 03 로그 내보내기 — 메뉴 3, 그다음 5

로그는 원할 때만 내보내면 됩니다. 내보내지 않아도 제품 동작에는 아무 영향이 없습니다. CMU에는 최근 기록이 약 48 MiB까지 남고, 오래된 것부터 지워집니다.

**v1.0.5부터 내보낸 기록은 CMU에서 지웁니다.** 메뉴 3(터치 `SAVE LOGS`)이 로그를 닫고 USB에 쓴 뒤 다음이 모두 맞으면 내보낸 기록 파일(`trace.*`, `collector.*`, `pimu.*`)을 지웁니다: 이번 부팅의 기록이 멈췄다는 표시, USB 파일을 다시 읽은 해시 일치, 지울 파일마다 같은 크기로 묶음에 들어 있음. 그래서 다음 내보내기에는 그 뒤 기록만 들어가고 금방 끝납니다. 하나라도 어긋나면 아무것도 지우지 않습니다(`prune=skipped` 또는 `nothing deleted`). 설치 기록, guard 상태, G3 방위 기록, 메뉴 표식은 지우지 않습니다. **지운 뒤에는 USB의 tar가 유일한 사본입니다.**

## 순서 (주차 중)

1. 설치 때의 ZIP 내용물이 들어 있는 USB를 씁니다(같은 USB면 됩니다). 빈 공간은 100 MB 이상을 권합니다.
2. 곡을 재생해 셸을 열고 메뉴를 엽니다.
3. `3`. 최대 15초쯤 걸립니다. 끝나면 `Result saved:` 줄이 나오고 메뉴가 저절로 닫힙니다.
4. **메뉴를 다시 열고 `5`**(CMU 재부팅). 이것을 잊지 마십시오.
5. 재부팅 뒤 메뉴를 열고 `2`로 `GO`를 확인합니다.

**왜 5가 필요합니까.** 메뉴 3은 로그를 안전하게 닫으려고 **그 부팅 동안** 제품을 멈춥니다. `5`를 누르지 않고 그대로 운행하면 그 운행은 순정으로만 동작합니다(다음 시동부터는 다시 켜집니다).

## USB에 생기는 파일

| 파일 | 내용 |
| --- | --- |
| `mx5dr-logs-<날짜시각>-<번호>.tar.gz` | 제품 기록 전체, gzip 압축(아래 주의). v1.0.6부터이며, 압축을 쓸 수 없는 CMU에서는 `.tar` |
| `trial-result.txt` | 내보내기 결과 요약(`export_exit=0`이면 성공, `prune=done`이면 CMU의 내보낸 기록을 지움) |
| `startup-result.txt` | 앞서 메뉴 2를 눌렀다면 그 결과(메뉴 3이 만들지는 않음) |

CMU 시계는 1970년 근처에 있으므로 파일 이름의 날짜는 실제 날짜가 아닙니다.

## 개인정보 주의

- tar·tar.gz 파일에는 **정밀한 위치 이력**(주행 경로, 특히 터널·지하 구간과 정차 위치)과 주행 시각이 들어 있습니다. 화면에도 `Keep it private.`가 나옵니다.
- 인터넷·공개 저장소·단체 대화방에 올리지 마십시오.
- 블루투스 장치 주소는 제품 기록에 쓰지 않습니다.

## 실패했을 때

- `export_exit=0`이 아니면 USB 공간과 USB가 꽂혀 있는지 확인하고 `3`을 다시 합니다. 이때는 아무것도 지우지 않았으므로 로그는 CMU에 그대로 남아 있습니다.
- 어떤 경우에도 마지막에는 메뉴를 다시 열고 `5`입니다.
