# 폰 자이로 기록 설치와 주차 확인 (beta.16 이후)

이 기능은 **기록 전용**입니다. 네이버로 가는 위치와 차의 동작은 바뀌지 않습니다. 폰 자이로 값을 차의 yaw 옆에 기록해 두었다가, 다음 버전에서 쓸지 데이터로 판단합니다. 근거와 설계는 `validation/PHONE_IMU_CHANNEL_2026-10-14.md`에 있습니다.

## 1. 차 (주차 중, USB)
평소와 같습니다.
1. USB 메뉴 `1` (설치) → `5` (CMU 재부팅).

## 2. 폰 (한 번만)
1. 릴리즈 페이지에서 `mx5imu-sender` APK를 받아 설치합니다(출처를 알 수 없는 앱 설치 허용 필요). 위치·인터넷 권한이 없는 앱입니다.
2. 앱을 열고 **권한 허용** → '근처 기기'와 '알림'을 허용합니다.
3. 목록에서 **차(CMU) 이름을 한 번** 누릅니다(핸즈프리로 이미 페어링된 이름).
4. **송신 켜기**를 누릅니다.
5. **배터리 설정 열기** → 배터리 **제한 없음**. 설정 → 배터리 → 백그라운드 사용 한도 → **절전 예외 앱**에도 추가합니다.

이후에는 만질 것이 없습니다. 폰을 재부팅해도 다시 켜집니다.

## 3. 첫 시동 때 주차 상태 확인 (5~10분, 주행하지 않음)
1. 시동을 켜고 무선 동글로 안드로이드 오토가 평소처럼 연결되는지 봅니다.
2. 1~2분 안에 폰 알림이 **"CMU 연결됨 · 자이로 송신 중"**으로 바뀌는지 봅니다.
   - 차 화면에 Bluetooth 연결이나 페어링을 허용할지 묻는 창이 뜨면 **허용**을 누르십시오(뜰지는 아직 모릅니다).
3. 그대로 5~10분 두고 **안드로이드 오토와 핸즈프리가 끊기지 않는지** 봅니다.

## 4. 결과별 행동
| 폰 알림 / 차 | 할 일 |
|---|---|
| "CMU 연결됨 · 자이로 송신 중", AA·핸즈프리 정상 | 그대로 주행하십시오. 끝나면 평소처럼 메뉴 `3`으로 내보내 올려 주십시오. |
| 계속 "연결 대기 중", AA·핸즈프리 정상 | 주행해도 됩니다(자이로 기록만 안 됨). 주차 후 메뉴 `2` 결과를 올려 주십시오. |
| AA나 핸즈프리가 끊기거나 CMU가 재부팅됨 | 앱에서 **송신 끄기** → USB 메뉴 `11`, 한 번 더 `11`(Bluetooth 끔) → 메뉴 `5`. 메뉴 `3`으로 내보내고 앱의 **진단 기록 내보내기** 파일과 함께 올려 주십시오. |
| "연결 반복 실패 · N분 동안 중지" | 폰 안전장치가 잠시 멈춘 것입니다. 차는 그대로 쓰십시오. N분 뒤 스스로 다시 시도합니다. 진단 기록을 올려 주십시오. |
| "연결 중지됨 · 앱에서 '지금 다시 시도'" | 폰 안전장치가 완전히 멈춘 것입니다. 앱을 열거나 폰을 재부팅해도 풀리지 않습니다. 진단 기록과 메뉴 `3` 결과를 먼저 올려 주십시오. 다시 쓰려면 앱의 **지금 다시 시도**를 누르십시오(한 번 누르면 최대 3번 더 시도하고, 또 실패하면 다시 멈춥니다). |

차(CMU)에도 자동 안전장치가 있습니다. 차의 Bluetooth 데몬이 이 기능 때문에 재시작되거나 멈추면 차는 그 부팅 동안 스스로 멈추고, **다음 시동부터는 이 기능을 끈 채로** 뜹니다(메뉴 `1`을 다시 해야 켜짐).

**중요: 차 쪽이 꺼진 동안(메뉴 `11`로 끔, 또는 위 자동 안전장치) 폰은 연결에 계속 실패하므로 늦어도 다음 주행 안에 "연결 중지됨"으로 멈춥니다.** 정상입니다. 차 쪽을 다시 켠 뒤(메뉴 `1` 또는 메뉴 `11` → `11`, 그다음 메뉴 `5`) 앱에서 **지금 다시 시도**를 한 번 누르십시오.

## 5. 끄기와 다시 켜기
- 차를 끔: USB 메뉴 `11` → `11` → 메뉴 `5`. 다시 켬: 같은 순서(또는 메뉴 `1` → `5`). **다시 켠 뒤 앱에서 지금 다시 시도**를 누르십시오.
- 폰: 앱의 **송신 끄기**(알림에서도 가능). 완전히 지우려면 앱 삭제.

## 6. (선택) OBD 어댑터로 차량 yaw 기록 (2단계, 기록 전용)
OBD 단자에 블루투스 어댑터(JF327 등)를 꽂아 두면, 앱이 휴대폰 자이로 대신 차량 자체의 yaw(CAN 0x079)를 같은 방식으로 보내 차의 기록에 남깁니다. 이것도 **기록 전용**이며 네이버로 가는 위치는 바뀌지 않습니다.
1. 먼저 `docs/OBD_YAW_CHECK_KO.md`의 **주차 10분 점검**을 하십시오(시동 ON, Car Scanner 종료).
2. 앱의 'OBD 어댑터' 목록에서 어댑터를 한 번 고릅니다. 다음 CMU 연결부터 적용됩니다.
3. 어댑터가 잘 들어오면 앱이 스스로 차량 yaw를 보내고, 끊기면 바로 자이로로 돌아갑니다. 화면의 '보내는 값'에 지금 무엇을 보내는지 나옵니다.
4. 끄려면 목록에서 **OBD 사용 안 함**을 고릅니다. Car Scanner를 쓰려면 송신을 끄거나 OBD 사용 안 함을 고르십시오(어댑터는 앱 하나만 받습니다).

## 개인정보
앱의 진단 기록에는 **차(CMU)의 Bluetooth 주소**가 들어갑니다. 공개된 곳에는 올리지 마십시오. 자이로 원본 값은 폰에 저장되지 않고 차의 기록에만 남습니다.

**로그 내보내기(v0.2.1 이후)**: '진단 기록 내보내기'를 누르면 로그가 폰의 **다운로드 폴더**에 `mx5imu-log-날짜-시각.txt` 파일로 저장되고(화면에 이름과 크기가 나옵니다) 공유 창도 열립니다. 공유 대상 앱이 파일을 이상하게 처리하면(예: 파일 경로만 글자로 올림) 공유 창은 닫고 파일 관리자에서 이 파일을 직접 골라 올리십시오. 다운로드 폴더는 다른 앱도 읽을 수 있으니 어댑터·CMU의 Bluetooth 주소가 들어 있는 이 파일은 올린 뒤 지우십시오.
