# 현재 상태와 인계 — 최신 발행 v1.0.4, 안정 기준 v1.0.0 (2026-11-01)

이 문서는 새 리뷰어·LLM의 첫 진입점이다. 과거 상세 설계와 설치 가능 판단보다 우선한다. 호스트·ARM·QEMU·순정 BusyBox 복제·재생과 실제 차량 검증을 구분한다. 소스 커밋과 공개 릴리즈는 별개다.

## 지금의 사실

- **최신 발행판은 v1.0.4다(2026-11-01)**: 브랜치 `release/v1.0.4`(같은 날 master에 병합, 태그는 릴리즈 커밋에 그대로), 커밋 `734bf9f`, ZIP SHA-256 `31d0b473…7d27`. 여섯 ARM 산출물은 v1.0.0~v1.0.3과 바이트 동일하다. 다른 도구(mazda-cmu-tune)가 sm.conf를 바꾼 뒤 재설치 없이 다시 등록하는 `tools/rebaseline.sh`와 버전 표시를 더했다(계약: [INTEROP_KO.md](INTEROP_KO.md)). 실차·QEMU ARM guard 미실행. 기록: validation/REBASELINE_2026-11-01.md, validation/RELEASE_V104_2026-11-01.md. **master는 v1.0.4보다 앞서 있다**: 아래의 미발행 후보(터널 지도 등)와 master 터치 경로의 한 번 누르는 DELETE는 어떤 공개 ZIP에도 없다(v1.0.4는 v1.0.2/v1.0.3의 두 단계 REMOVE → DELETE FILES). 아래 v1.0.0 검증 상태 표는 그대로 유효하다.
- **안정 기준판은 v1.0.0이다**(고정 커밋 `bc9e5f3d82fc8c4153765a2c73bc43fd2602fb1e`, ZIP SHA-256 `c867a21aa8f9f0670c82b780027a72ce8928459430297e7ddb4d1e412a795187`; 발행 전에는 후보). v1.0.1~v1.0.4는 설치 경로·설치기·도구와 버전 표시만 바꿨고, 여섯 ARM 제품 바이너리와 기능 라벨은 같다. 추가 차량 방문·주행·로그 전달을 전제로 하지 않는다.

## 미발행 후보 (2026-10-22): 터널 중심선 지도 구속
