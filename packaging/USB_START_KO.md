# 설치 안내 (한 장)

**이것은 무엇입니까.** 2019 MX-5 ND2, 1세대 Mazda Connect NA 74.00.324A 전용 묶음입니다.
설치하면 매 부팅 스스로 켜지는 BETA 모드로 실행되며, 순정이 GPS를 잃은 동안(터널 등)에만
안드로이드 오토로 보내는 위치·속도를 바꿔 보냅니다. 그 밖에는 순정 그대로 전달합니다.
CMU 리셋이 이어지면 스스로 순정으로 돌아갑니다. 실차에서 효과가 확인되지 않은 부분이 있으며,
실험 기능(아래 11·12)은 설치할 때마다 **꺼짐**으로 시작합니다.

입력은 아래 한 줄과 숫자만 사용합니다(소문자·숫자·공백·슬래시, Shift와 밑줄 없음).

```sh
sh /tmp/mnt/sda1/trial
```

## 설치

1. ZIP을 푼 **내용물 전체**를 FAT32 USB 최상위에 복사합니다. USB에 `trial`, `mp3`, `js`가 바로 보여야 합니다.
2. 환기되는 곳에 주차하고 주차브레이크·중립을 유지한 채 **엔진을 실제로 켜 둡니다**(타코미터 0보다 높음).
   ACC나 엔진이 꺼진 ON 상태로 하지 않습니다. 작업이 끝날 때까지 시동 버튼을 누르지 않습니다.
3. USB를 꽂고 Entertainment → USB에서 곡을 재생한 뒤 약 15초 기다립니다(셸이 열림).
4. 위 한 줄을 입력합니다. USB가 `sdb1` 등으로 잡히면 그 글자만 바꿉니다.
5. `1` 입력 → `Installation finished`가 나오면 `5` 입력(CMU 재부팅).
6. 화면이 돌아오면 3~4를 반복해 메뉴를 열고 `2`를 입력합니다.
   마지막 줄이 **`GO`**이고 **`ok   CONF  confirmed`** 줄이 있어야 합니다.
   `WAIT 60 s, then run 2 again`이면 60초 기다린 뒤 `2`를 다시 입력합니다.
7. `0`으로 나가 USB를 빼고 AA 동글을 연결합니다. USB와 동글은 동시에 꽂을 수 없습니다.

**`GO`가 아니면:** `4`(제거) → 메뉴를 다시 열어 `5`. 그 뒤에는 순정으로 동작합니다.
같은 화면을 사진으로 남기면 원인을 찾는 데 쓸 수 있습니다.

## 메뉴 번호

| 번호 | 하는 일 |
| --- | --- |
| 1 | 설치 또는 다시 켜기. 실험 기능 11·12를 꺼짐으로 되돌림 |
| 2 | 상태 확인(`GO`/`NO-GO`), USB에 `startup-result.txt` 저장 |
| 3 | 로그를 USB로 회수. 그 부팅 동안 제품이 멈추므로 **끝나면 반드시 메뉴를 다시 열어 `5`** |
| 4 | 제거(로그는 남김). 중단된 설치도 정리함 |
| 5 | CMU 재부팅 |
| 6 | 남은 파일 모두 삭제(`4` → `5` 뒤에만, `6`을 두 번 입력) |
| 7, 8, 10 | 기록·방위·터널 25 m 설정 켜기/끄기(기본 켜짐) |
| 11 | 실험: 폰 블루투스 채널 켜기/끄기(기본 **꺼짐**) |
| 12 | 실험: 지하 출구 방위 이월 켜기/끄기(기본 **꺼짐**) |
| 0 | 나가기 |

9번은 없습니다(이전 진단 메뉴는 제거됨). 7~12는 같은 번호를 한 번 더 입력해야 바뀌고,
바뀐 설정은 `5`로 재부팅한 뒤부터 적용됩니다. 메뉴 `2`의 `EXP` 줄이 켜 둔 실험 기능을
보여 줍니다(`EXP none`이면 둘 다 꺼짐).

## 제거·되돌리기

- 제거: `4` → 메뉴를 다시 열어 `5` → 다시 열어 `2`에서 `stock this boot`를 확인합니다.
- 흔적까지 삭제: 위 제거 뒤 `6`을 두 번 입력합니다. 로그가 필요하면 먼저 `3`(그다음 `5`).
- 이전 판으로: 기본은 위의 제거(`4` → `5` → `2`)를 권합니다. 베타 17 이하 ZIP은 `1`에서 실험 기능(11, 12)을 **저절로 켭니다**(그 판의 기본값은 켜짐). 굳이 이전 ZIP을 쓰면 `1` 뒤 `5` 전에 `11`, `11`과 `12`, `12`를 입력해 끄십시오.
- 설치 중 전원이 꺼졌거나 `Install lock present` 또는 `Incomplete transaction`이 보이면:
  `4` → 메뉴를 다시 열어 `1` → `5` → `2`.

## 알아 둘 것

- 차는 제품이 꺼졌는지 알려 주지 않습니다. 몇 번 운행할 때마다 주차 중 `2`를 확인하십시오.
  `NO-GO: tripped`는 자동으로 순정으로 돌아간 상태이며, `3`으로 회수한 뒤 `1`로 다시 켭니다.
- 회수 파일(`mx5dr-logs-*.tar`)에는 위치 기록이 들어 있습니다. 공유하지 마십시오.
- 기존 AA 터치·km/L 패치는 다시 설치하거나 지우지 않습니다. 순정 서비스 설정과 블루투스 설정은
  고치지 않으며, 순정 시작 스크립트에는 이 묶음의 블록 두 개만 넣고 `4`가 그대로 뺍니다.
- `mp3`·`js`는 셸을 여는 데만 씁니다. 출처는 `USB_ENTRY_NOTICE.md`에 있습니다.
