# USB 설치

대상은 1세대 Mazda Connect **NA 74.00.324A**입니다.
차량 USB 포트는 하나이며 허브를 사용할 수 없습니다. 설치·회수용 USB와
유선 AA는 주차 중에 번갈아 연결하십시오. AA 사용 중 셸을 열 필요는 없습니다.

**이전 v0.3.9-shadow.1에서 메뉴 3 회수가 실패한 경우:** 수정판의 내용물로
USB 파일을 교체하고, 아래 한 줄로 메뉴를 열어 **`3`과 Enter만** 누르십시오.
이미 `4`로 제거했어도 차량에 남은 로그를 회수할 수 있습니다. 재설치나
재주행은 필요하지 않습니다. USB에 기존 결과 파일이 있다면 먼저 PC에 보관하십시오.
현재 부팅의 종료 확인이 실패해도 `export_exit=0`이면 남은 파일은 회수된 것입니다.
실제로 남아 있는 기록의 범위와 계산 결과는 회수 후 확인합니다.

1. ZIP을 푼 **내용물 전체**를 깨끗한 FAT32 USB 최상위에 복사하십시오.
   USB를 열었을 때 `trial`, `install.sh`, `mp3/`, `js/`가 바로 보여야 합니다.
2. 주차 상태에서 USB와 키보드를 연결하십시오. Entertainment → USB에서
   곡을 재생하고 약 15초 기다리십시오. 진단 셸이 열립니다.
   다른 USB가 먼저 연결되어 있으면 다음 곡도 재생하십시오.
3. 셸에서 다음 한 줄로 숫자 메뉴를 여십시오. 소문자·숫자·공백·슬래시만
   사용하므로 Shift가 필요하지 않습니다.

   ```sh
   sh /tmp/mnt/sda1/trial
   ```

   USB가 `sdb1`, `sdc1`, `sdd1`로 잡히면 경로의 해당 글자만 바꾸십시오.
   별도 `sha256sum`, `chmod`, `chown`, `mount` 명령은 필요하지 않습니다.
4. **최초 설치인 경우에만 숫자 `1`과 Enter**로 설치하십시오. 이전 시험 자료를
   회수하려면 `1` 대신 **`3`과 Enter**를 누르십시오. 설치 명령이 성공으로 끝나면 셸 사용을
   마치고 설치 USB를 분리하십시오. 유선 AA를 연결하고 정상적으로 전원을
   껐다 켜십시오.
   다음 한 번의 부팅에서 묶음에 지정된 모드로 자동 수집합니다.
   SHADOW 묶음은 위치 계산을 로그로만 기록하며 폰으로 전송하지 않습니다.

기존 AA 터치와 km/L 패치는 유지됩니다. 이 묶음의 MP3/JS는 셸만 열며
기존 터치 패치를 다시 설치하지 않습니다. 설치 중에는 USB를 빼지 마십시오.

시험 부팅에서 기존 AA·터치가 정상인지 주차 중 화면으로 확인하십시오.
정상 동작을 확인할 수 없으면 주행하지 말고 아래 회수 절차로 자료를 보존하십시오.
**`2`는 선택 진단이며 수집 시작 조건이 아닙니다.** USB를 빼도 설치된 차량
내부 파일로 자동 수집합니다. AA와 USB를 동시에 연결하려고 하지 마십시오.

| 번호 | 동작 |
| --- | --- |
| 1 | 최초 설치, 다음 한 번의 부팅 예약 |
| 2 | 선택 사항: 현재 상태와 보존 기록 요약 확인, 모드 변경 없음 |
| 3 | 수집 종료 요청과 현재 USB로 자료 저장 |
| 4 | 제거, 기존 수집 로그 보존 |
| 0 | 메뉴 종료 |

빈 Enter나 입력 종료로 자동 설치하지 않습니다. 시험 부팅 후 다시 `1`을
선택할 필요는 없습니다. 수집·계산은 자동으로 실행됩니다.

`2` 또는 회수 시 출력되는 최근 상태는 **조회하는 현재 부팅**의 진단입니다.
AA 분리나 재부팅 뒤의 `unavailable`은 이전 시험에서 한 번도 기록·계산하지
않았다는 뜻이 아닙니다. 수락된 원시 수신, OEM 위치, 계산 시도를 각각 표시합니다.
`calculation_attempt_recent`은 주 계산기의 실제 호출 근거이고,
`events_queued_total`은 대기열 등록 수입니다. 둘 다 유효 해의 개수가 아닙니다.
`model_solution=not_observed`이면 현재 유효 계산 결과가 확인되지 않은 상태입니다.
정차 중 기준점을 기다릴 수 있으므로 함께 표시된 `pipeline`과
`gps_anchor_gate`를 확인하십시오. 기동 확인 성공이 시험 완료를 뜻하지는 않습니다.
`last_pipeline_reset_this_boot`은 이후 입력이 정상이어도 보존한 최근 계산 초기화 사유입니다.
이 사유와 원시 입력은 회수한 로그에서 함께 분석합니다.
상태 명령의 성공은 원시 수집 근거를 뜻합니다. 계산·위치가 `unavailable`이면
그 사유도 보존하며, 거부된 입력은 수락된 수신과 별도로 표시합니다.
`retained_runtime_last_boot`와 `retained_model_diagnostic_records`는 마지막
보존 부팅에 연결된 기록 요약입니다. 행 수는 계산 호출 수·정확도·시험 성공을
뜻하지 않습니다. boot 표식이 회전으로 사라졌다면 부팅을 추정하지 않습니다.

설치기는 필요한 저장 공간을 먼저 확인합니다. 실행 중에도 공간이 부족해지면
기록을 중단하고 사유를 남기며, 기존 로그를 지워서 계속 수집하지 않습니다.
로그는 최대 26MiB이며 설치 파일·설정 백업은 별도입니다. 8MiB 여유 정책은
다른 프로그램의 동시 쓰기나 파일시스템 고장까지 방지하는 보장은 아닙니다.

운전 중에는 명령을 입력하거나 USB를 바꾸지 마십시오. 도착 후 주차 상태에서
AA를 분리하고 같은 설치 USB를 연결하십시오. 곡을 재생하여 셸로 돌아온 뒤
위 한 줄로 메뉴를 열고 **바로 `3`과 Enter**로 종료·회수하십시오. `2`를 먼저
누를 필요는 없습니다. 실행한 USB에 자동 저장하므로 목적지 경로를 입력하지
않습니다. 저장 중에는 USB를 연결해 두십시오.

가능하면 같은 부팅에서 회수하십시오. 셸 복귀에 정상 재부팅이 필요하면
재부팅한 뒤 같은 USB에서 `3`을 실행하십시오. 다시 `1`을 누르거나 시험을
재무장하지 마십시오. 한 번의 시험 부팅 예약은 이미 소비되었으며, 이후 부팅은
기본 설정으로 복귀합니다. 이전 부팅의 남아 있는 로그도 함께 회수합니다.
재부팅 전 마지막 행의 저장이나 회전으로 사라진 자료까지 보장하지는 않습니다.

종료 확인이 실패해도 남은 파일의 회수를 시도합니다. USB의 `trial-result.txt`에
종료 전 상태와 `status_exit`, `finish_exit`, `export_exit`를 따로 남깁니다.
`finish_exit`는 **현재 부팅**의 종료 확인이고 `export_exit`는 **보존된 모든
부팅 자료**의 회수 결과입니다. 재부팅 후에는 이전 시험의 완료 표식이 있어도
`finish_exit`가 0이 아닐 수 있습니다. 이를 현재 부팅의 정상 종료나 이전 시험의
실패로 바꾸어 해석하지 마십시오. `export_exit=0`이면 확보 가능한 파일의 회수는
성공한 것입니다. 완료되지 않은 끝부분·누락·계산 결과는 PC에서 별도로 분석합니다.
`export_exit`가 0이 아니면 회수 성공으로 간주하지 마십시오.
이 작은 결과 파일은 다음 회수 때 교체하며 CMU에 누적하지 않습니다.
로그 archive, `.sha256`, `trial-result.txt`를 함께 가져오십시오.
PC에서 archive의 `.sha256`을 확인하십시오. 회수 후 차량 원본은
남으며 로그는 위 상한에서 관리됩니다. 차량 내부에 archive를 만들지 마십시오.

제거할 때는 메뉴에서 **`4`와 Enter**를 누르십시오.
다음 정상 부팅부터 적용되며 기존 터치 설정과 수집 로그는 보존합니다.

이 패키지는 설치 오류를 수정한 시험 후보입니다. 실제 CMU에서의 기동,
센서 수신 및 폰/지도 앱 수용은 아직 검증하지 않았으며 ASSIST는 꺼져 있습니다.
