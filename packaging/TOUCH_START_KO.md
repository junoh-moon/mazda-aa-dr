# 터치 설치 안내 (키보드 없이)

**무엇입니까.** USB를 꽂으면 화면에 뜨는 버튼만 눌러 설치·점검·제거합니다.
키보드와 숫자 입력이 필요 없습니다. 대상은 2019 MX-5 ND2, 1세대 Mazda Connect
NA 74.00.324A입니다. 설치하면 BETA 모드가 매 부팅 스스로 실행됩니다. 실험 기능은 꺼짐입니다.

**아직 확인되지 않은 것.** 이 경로는 실차에서 아직 확인되지 않았습니다. USB를 꽂았을 때
대화상자가 뜨는지, 버튼이 기대대로 동작하는지 차량에서 확인해야 합니다. 대화상자가 뜨지 않으면
`SHELL_INSTALL_KO.md`의 숫자 메뉴 절차를 따르십시오(그 절차에는 키보드가 필요합니다).

## 준비 (집이나 PC에서)

1. ZIP을 풀고 **내용물 전체**를 FAT32 USB 최상위에 복사합니다.
2. USB 최상위에 `touch.sh`, `trial`, `MX5DR-TOUCH.ID`, `jci-autoupdate`, 그리고 이름이
   `$(`로 시작하는 `.up` 파일이 보여야 합니다. 파일 이름을 직접 입력하거나 바꾸지 마십시오.

## 설치 (주차 중, 약 5분)

1. 환기되는 곳에 주차하고 주차브레이크를 겁니다. **엔진을 실제로 켜 둡니다**(ACC나 엔진이 꺼진
   ON 상태가 아님). 설치가 끝날 때까지 시동 버튼을 누르지 않습니다.
2. 차를 켠 상태에서 USB를 꽂습니다. `Install MX5 AA DR (BETA)?` 대화상자가 나오면 `INSTALL`을
   누릅니다. 30초 안에 뜨지 않으면 USB를 뺐다가 다시 꽂습니다.
3. `Installing MX5 AA DR.` 화면이 사라질 때까지 기다립니다. USB는 꽂아 둡니다.
4. `Installed.` 대화상자가 나오면 `RESTART`를 누릅니다. CMU가 다시 시작됩니다.
   `LATER`를 누르면 지금은 재시작하지 않습니다. 재시작 전에는 BETA가 시작되지 않으며,
   나중에 `MORE`의 `RESTART`로 재시작할 수 있습니다.

## 재시작 후 점검 (주차 중)

1. CMU 화면이 돌아오면 USB를 다시 꽂습니다. `MX5 AA DR is installed.` 대화상자가 나오면
   `CHECK`를 누릅니다.
2. `Check: GO`가 나오면 점검이 통과한 것입니다. `NO-GO`나 `WAIT 60 s, then run 2 again`이면
   대화상자의 안내를 따릅니다. `WAIT`는 60초 뒤 `CHECK`를 다시 누릅니다. `NO-GO`이면 USB를
   그대로 두고 `MORE`에서 `SAVE LOGS`를 누릅니다.
3. 결과는 USB의 `startup-result.txt`와 `touch-log.txt`에 저장됩니다.
4. 점검이 끝나면 USB를 빼고 무선 AA 동글을 연결합니다. 주차 중에만 바꿉니다.

## 제거

USB를 꽂고 `REMOVE`를 누른 뒤 확인 대화상자에서 `REMOVE`를 누릅니다. `Removed.` 대화상자에서
`RESTART`를 누르면 재시작 뒤 순정으로 돌아옵니다.

## 로그 저장과 완전 삭제

- `MORE`의 `SAVE LOGS`: 로그를 USB에 저장합니다. 저장하는 동안 이 부팅의 제품이 멈추며,
  다음 부팅에 다시 시작합니다.
- `MORE`의 `DELETE ALL`: 제거와 재시작을 마친 뒤에만 됩니다. 두 번 확인합니다. 수집 로그도
  지워지므로 먼저 `SAVE LOGS`로 저장하십시오. 지운 내용은 되돌릴 수 없습니다.

## 하지 말 것

- 운전 중에는 USB를 꽂거나 화면을 누르지 마십시오. 모든 단계는 주차 중에 합니다.
- `touch.sh`, `trial`, `.up` 파일을 손으로 고치지 마십시오.
- `touch-log.txt`와 회수 파일에는 차량 정보가 들어갈 수 있습니다. 공유하기 전에 확인하십시오.
