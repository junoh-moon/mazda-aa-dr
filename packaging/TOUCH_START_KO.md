# 터치 설치 안내 (키보드 없이)

**무엇입니까.** USB를 꽂으면 화면에 뜨는 버튼만 눌러 설치·점검·로그 저장·재설치·제거·삭제를
합니다. 키보드와 명령 입력이 필요 없습니다. 대상은 2019 MX-5 ND2, 1세대 Mazda Connect
NA 74.00.324A입니다. 설치하면 BETA 모드가 매 부팅 스스로 실행됩니다. 실험 기능은 꺼짐입니다.

**실차에서 확인된 것.** 설치(2026-11-01 차량 기록), `CHECK`와 `SAVE LOGS`(2026-11-03 차량
기록, v1.0.4)는 이 경로로 차에서 실행됐습니다. 삭제(`DELETE`, 이 master 빌드의 한 번 누르는
흐름), 그리고 v1.0.5에서 바뀐 동작(아래 두 항목)은 아직 차에서 실행되지 않았습니다. 대화상자가 뜨지 않으면
`SHELL_INSTALL_KO.md`의 숫자 메뉴 절차를 따르십시오(그 절차에는 키보드가 필요합니다).

**버튼 규칙.** 2개 버튼 확인 창에서는 **왼쪽이 항상 안전한 선택**(취소나 나중에)이고,
실제로 실행하는 버튼은 **오른쪽**입니다. 실수로 왼쪽을 눌러도 아무 일도 일어나지 않습니다.

## 준비 (집이나 PC에서)

1. 릴리즈 ZIP을 풀고 **내용물 전체**를 FAT32 USB 최상위에 복사합니다.
2. 최상위에 `touch.sh`, `trial`, `MX5DR-TOUCH.ID`, `jci-autoupdate`, 그리고 이름이
   `$(`로 시작하는 `.up` 파일이 보여야 합니다. 파일 이름을 직접 입력하거나 바꾸지 마십시오.

## 화면은 상태에 따라 세 가지입니다

- **설치 전**: `Install MX5 AA DR (BETA)?` 창이 뜹니다.
- **설치됨**: `MX5 AA DR is installed.` 창에서 `CHECK`, `SAVE LOGS`, `MORE`를 고릅니다.
- **제거됨(파일 남음)**: `SAVE LOGS`, `REINSTALL`, `DELETE FILES`를 고릅니다.

## 설치 (주차 중, 약 5분)

1. 환기되는 곳에 주차하고 주차브레이크를 겁니다. **엔진을 실제로 켜 둡니다**(ACC나 엔진이 꺼진
   ON 상태가 아님). 설치가 끝날 때까지 시동 버튼을 누르지 않습니다.
2. 차를 켠 상태에서 USB를 꽂습니다. `Install MX5 AA DR (BETA)?` 창이 나오면 오른쪽
   `INSTALL`을 누릅니다. 30초 안에 뜨지 않으면 USB를 뺐다가 다시 꽂습니다.
3. `Installing MX5 AA DR.` 화면이 사라질 때까지 기다립니다. USB는 꽂아 둡니다.
4. `Installed.` 창에서 `RESTART`를 누릅니다. CMU가 다시 시작되고 BETA가 처음 실행됩니다.
   `LATER`를 누르면 지금은 재시작하지 않습니다.

## 재시작 후 점검

설치나 `REINSTALL` 뒤 첫 부팅은 점검 대상입니다. v1.0.5부터는 점검이 끝나기 전(약 2분)에
시동을 꺼도 제품이 꺼지지 않고 다음 부팅에서 다시 점검합니다. 주차하며 시동을 짧게 켰다 끄는
것도 제품을 끄지 않습니다. CMU가 스스로 리셋되는 일이 이어질 때만 순정으로 돌아갑니다
(`NO-GO`, `REINSTALL`로 다시 켬).

1. CMU 화면이 돌아오면 USB를 다시 꽂습니다. `MX5 AA DR is installed.` 창에서 `CHECK`를 누릅니다.
2. `Check: GO`가 나오면 통과입니다. `NO-GO`나 `WAIT 60 s, then run 2 again`이면 창의 안내를
   따릅니다. `WAIT 60 s, then run 2 again`은 60초 뒤 `CHECK`를 다시 누릅니다. `NO-GO`이면
   `SAVE LOGS`로 로그를 저장한 뒤 `MORE`의 `REINSTALL`로 다시 켤 수 있습니다.
3. 결과는 USB의 `startup-result.txt`와 `touch-log.txt`에 저장됩니다.
4. 점검이 끝나면 USB를 빼고 무선 AA 동글을 연결합니다.

## 로그 저장·재설치

- **로그 저장**: 설치됨 창의 `SAVE LOGS`. 저장하는 동안 이 부팅의 제품이 멈추며, 다음 부팅에
  다시 시작합니다.
- **저장한 기록은 CMU에서 지워집니다(v1.0.5부터).** USB에 쓴 뒤 다음이 모두 맞을 때만
  지웁니다: 이번 부팅의 기록이 멈춤, USB 파일을 다시 읽은 체크섬이 맞음, 지울 파일마다 같은
  크기로 USB 묶음에 들어 있음. 하나라도 어긋나면 아무것도 지우지 않습니다. 그래서 다음 저장에는
  그 뒤 기록만 들어가고 빨리 끝납니다. 설치 기록, 점검 상태, 방위 기록은 지우지 않습니다.
  결과는 USB의 `trial-result.txt`의 `prune=` 줄에 있습니다(`prune=done`이면 지움).
  **지운 뒤에는 USB의 `mx5dr-logs-….tar`가 유일한 사본입니다.** PC로 옮겨 두십시오.
- **재설치·다시 켜기·업데이트**: `MORE` → `REINSTALL`. 트립(`NO-GO`) 뒤 다시 켜거나, 같은
  스틱의 새 번들로 업데이트할 때 씁니다. 실험 설정은 기본값으로 돌아갑니다.

## 삭제 (기능 + 로그 한 번에)

삭제는 **버튼 하나**입니다. 기능을 지우면서 남은 로그·백업까지 정리합니다. 다만 이 차량은
실행 중인 제품이 자기 파일을 붙들고 있어, **중간에 재시작이 한 번** 필요합니다(제품이 그래야
파일을 놓습니다). 그 재시작은 자동으로 일어납니다.

1. 설치됨 창의 `MORE` → `DELETE`를 누릅니다. 로그·백업까지 지워지므로, 남기고 싶으면 먼저
   `SAVE LOGS`로 저장하십시오. 확인하면 기능을 제거하고 **CMU가 자동으로 재시작**합니다.
2. 화면이 돌아오면 **USB를 다시 꽂기만** 하면 됩니다. "남은 파일을 삭제하시겠습니까" 확인이
   바로 떠서, 한 번 확인하면 로그·파일이 모두 지워집니다. 지운 내용은 되돌릴 수 없습니다.

즉 `DELETE → 확인 → (자동 재시작) → 재삽입 → 확인 → 끝`입니다. 재시작 전에는 제품이 파일을
붙들고 있어 삭제가 미뤄지며, 창이 재시작을 다시 안내합니다.

기능만 끄고 로그는 남기려면(나중에 `REINSTALL`로 다시 켤 때) 삭제 대신 `MORE`의 `REINSTALL`
계열을 쓰지 말고, 삭제를 누르지 않은 채 두면 됩니다. 삭제는 항상 전부를 지웁니다.

## 하지 말 것

- 운전 중에는 USB를 꽂거나 화면을 누르지 마십시오. 모든 단계는 주차 중에 합니다.
- `touch.sh`, `trial`, `.up` 파일을 손으로 고치지 마십시오.
- `touch-log.txt`와 회수 파일에는 차량 정보가 들어갈 수 있습니다. 공유하기 전에 확인하십시오.
