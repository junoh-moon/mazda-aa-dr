# MX5DR IMU 송신기 (휴대폰 앱, 1단계: 기록 전용)

휴대폰 자이로의 회전량(중력 축 기준, 20 ms 단위)을 Bluetooth로 차량 CMU에 보내는 앱입니다.
1단계에서 CMU는 이 값을 차량 자체 yaw 옆에 **기록만** 합니다. 내비게이션에 보내는 위치,
추측 항법 입력, 차량 동작은 바뀌지 않습니다. 실제 차량·S25에서 아직 실행하지 않았습니다.

## 개인정보와 권한

- 위치 권한과 인터넷 권한이 **없습니다**. 앱은 페어링된 차량 하나와만 통신합니다.
- 센서 값은 휴대폰에 저장하지 않습니다. 앱 내부에는 연결·오류·개수만 담은 진단 기록(최대 1 MB)만 남습니다.
- 사용 권한: 근처 기기(BLUETOOTH_CONNECT), 알림(POST_NOTIFICATIONS), 포그라운드 서비스
  (connectedDevice 종류), 화면이 꺼져도 센서를 받기 위한 WAKE_LOCK(차량 연결 중에만),
  재부팅 후 자동 시작(RECEIVE_BOOT_COMPLETED). Android 11에서만 BLUETOOTH(설치 시 권한)를 씁니다.

## 설치와 처음 한 번 설정

1. 개발 PC가 만든 `mx5imu-sender.apk`를 휴대폰에 복사하여 설치하십시오(출처를 알 수 없는 앱 설치 허용 필요).
2. 앱을 열고 **권한 허용**을 누른 뒤 '근처 기기'와 '알림'을 허용하십시오.
3. 목록에서 차량(CMU)을 한 번 누르십시오. Android Auto·핸즈프리용으로 이미 페어링된 이름입니다.
4. **송신 켜기**를 누르십시오.
5. **배터리 설정 열기** → 배터리 → **제한 없음**을 선택하십시오. Samsung은 오래 쓰지 않은 앱을
   '절전 상태'로 두어 백그라운드 서비스를 멈출 수 있으므로, 설정 → 배터리 → 백그라운드 사용 한도
   → **절전 예외 앱**에도 이 앱을 추가하십시오.

그 뒤에는 조작이 필요 없습니다. 휴대폰을 재부팅해도 송신이 켜져 있었다면 자동으로 다시 시작합니다.

## 알림의 의미

송신이 켜져 있는 동안 'MX5DR IMU 송신' 알림이 항상 표시됩니다(Android 규칙).

- **연결 대기 중**: 차량을 기다리는 중입니다. 차량 Bluetooth가 연결되면 연결을 시도하고(실패가
  남아 있지 않을 때만 바로), 실패하면 2초에서 30초 간격으로 다시 시도합니다. 간격은 PING을 60초 이상
  받은 연결 뒤에만 2초로 돌아갑니다. 이 상태에서는 센서를 쓰지 않습니다.
- **CMU 연결됨 · 자이로 송신 중**: CMU의 첫 시간 확인(PING)을 받은 뒤부터 초당 50개의 회전량 프레임을
  보냅니다(첫 PING 전에는 아무 데이터도 보내지 않고, 15초 안에 PING이 없으면 끊습니다). PING에는 즉시
  응답합니다. 마지막 PING이 11초보다 오래되면 데이터를 잠시 멈추고, 15초 동안 PING이 없으면 연결을 끊고 다시
  연결합니다(PING 하나를 잃어도 끊기지 않음).
- **연결 반복 실패 · N분 동안 중지**: 차가 있는 상태(차량 Bluetooth 연결됨)에서 연결 실패나 PING을 하나도 받지
  못한 연결(15초 대기)이 연속 3번이면 60분 동안 시도하지 않습니다. PING을 받은 연결은 어떻게 끝나도 세지 않습니다
  (차량 Bluetooth가 이 서비스 때문에 재시작되는 경우를 막는 회로 차단기). 차가 없을 때(집, 폰 재부팅 직후)의
  실패는 세지 않습니다. 차량 Bluetooth가 다시 연결돼도 기다립니다.
- **연결 중지됨 · 앱에서 '지금 다시 시도'**: 차단이 두 번째로 걸린 상태입니다. 앱을 열거나 폰을 재부팅해도
  풀리지 않습니다(차단 상태는 저장됨). 앱의 **지금 다시 시도** 버튼만 풀며, 누를 때마다 최대 3번 더 시도한 뒤 또 실패하면 다시
  멈춥니다. 원인을 확인하기 전에는 누르지 말고 진단 기록을 보내 주십시오.

차량 쪽에서 이 서비스가 꺼지면(CMU 메뉴 11, 또는 CMU의 자동 안전장치) 차가 있는 상태의 연결이 계속 실패하므로 폰은 늦어도 다음 주행 안에 '연결 중지됨'으로 멈춥니다. 차 쪽을 다시 켠 뒤 앱의 **지금 다시 시도**를 한 번 누르십시오.

## 끄는 방법

앱의 **송신 끄기** 또는 알림의 **송신 끄기**를 누르십시오. 꺼진 동안은 아무 작업도 하지 않으며 재부팅 후에도 시작하지 않습니다.
완전히 지우려면 앱을 삭제하십시오.

## 문제가 있을 때

**진단 기록 내보내기**로 기록 파일을 공유(메일, 메신저, 파일 저장)하십시오. 연결·끊김 이유·오류·프레임 개수와
**선택한 차량(CMU)의 Bluetooth 주소**가 들어 있습니다(주소는 기기 식별 정보이므로 공개 장소에 올리지 마십시오).
앱 화면의 '최근 오류'도 함께 알려 주십시오. 왕복 시간(RTT)과 시계 차이는 CMU가 계산하여 CMU 기록에 남깁니다.

## 개발자용

```sh
phone/imu-sender/test.sh          # 호스트 시험(JDK 11+, python3)
phone/imu-sender/build.sh [SDK]   # 서명된 디버그 APK: phone/imu-sender/build/mx5imu-sender.apk
python3 tests/phone_imu/make_golden.py   # 양쪽 공용 골든 벡터 재생성(결정적, tests/phone_imu/golden_frames.json)
```

서명 키는 git에 포함되지 않는 `build/`에서 처음 빌드할 때 만들어집니다. 프로토콜은 'PHONE IMU CHANNEL v1'
(UUID `fae57779-63aa-4424-bf71-66ce5951b0be`, RFCOMM, 리틀 엔디언, CRC-32)이며
`src/me/sixtyfive/mx5imu/core/Protocol.java`와 `tests/imu_wire.py`가 각각 독립 구현입니다.
